# Bigtouch Theme

Kiosk layout theme plugin for Universal Till: the product-button grid spans the
full width at the top of the screen with extra-large touch targets; basket,
journal and tender sit below. Repositions panels via the `pos-container` grid
areas and enlarges tiles, buttons and inputs.

Asset-only plugin (`runtime: "none"`). Registers `type: "theme"` entry
(`key: bigtouch`); select it under Settings → Theme after install.
