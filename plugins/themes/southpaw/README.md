# Southpaw Theme

Layout theme plugin for Universal Till aimed at left-handed operators: the
product-button grid moves to the LEFT of the screen, the basket sits centre and
journal/tender stack on the right. It repositions panels purely via the
`pos-container` grid areas — no markup changes.

Asset-only plugin (`runtime: "none"`). Registers `type: "theme"` entry
(`key: southpaw`); select it under Settings → Theme after install.
