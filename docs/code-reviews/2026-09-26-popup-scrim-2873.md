# Review — shared popup scrim (ut-docs#2873)

- **Date:** 2026-09-26 · **Lane:** lane:cloud-24 · **Complexity:** medium

## What shipped
- `--ut-scrim` token (`app.css` `:root`; `themes/dark.css` retunes it). Global `dialog::backdrop` uses it (every `showModal()` dialog).
- One shared `#ut-scrim` (`base.html`, z 450) shown while any non-modal `.show()` dialog or `UT.popupOpened` panel is open, driven by ADR-0122 §5's hooks plus a `MutationObserver` backstop; every recompute prunes closed/disconnected/closing entries; all try-wrapped after the native call.
- Status bar and a dimmed, click-through rail lifted to 460 so status and **Lock** stay reachable (CLAUDE.md offline-first rule, #1999); exit-to-OS lives in Settings.
- Tap rule: a scrim/backdrop tap does nothing unless the topmost popup opts in (`data-ut-scrim-dismiss`: category filter popover, Sell category overflow, table QR). Opt-out `data-ut-no-scrim`: docked payment panel, bug-report panel.
- `.shrinkage-sheet` given `z-index: 500` (it painted under the scrim).
- e2e `popup-scrim-2873.spec.ts` (16 tests, incl. a 13-page sweep of every non-modal dialog and 1024×600/360×800 × en/fa × light/dark layout checks).
