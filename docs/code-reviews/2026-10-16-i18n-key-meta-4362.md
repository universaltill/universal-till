# Review: i18n key metadata + guard-i18n-meta.sh (ut-docs#4362)

- **Date:** 2026-10-16
- **Card:** ut-docs#4362 (ADR-0160 §2–§4, task 1; epic ut-docs#4354)
- **Author lane:** lane:cloud-24 (Opus 5.5); **reviewer:** independent Fable subagent

## What shipped

- `web/i18n-meta/en.meta.json`: per-key metadata (`description`, `review`,
  `placeholders`, `max_length`, `plural`, `area`, `review_exception`),
  outside `web/locales/` so `NewI18nFS`/`guard-i18n.sh` don't load it as a
  locale. Seeded with the 22 `common.*`/`app.name` keys as worked examples.
- `web/i18n-meta/areas.json`: 13 screen areas, every one of the 88 current
  namespaces mapped exactly once; `legal_namespaces` (receipt, invoice,
  fiscal, fiscaldevice, fiscalregister, tax, taxcodes, legal,
  shadow_documents).
- `scripts/ci/guard-i18n-meta.sh` + `_test.sh` (30 cases, sandboxed), wired
  into `ci.yml`'s build job with an `origin/main` fetch for the base-ref
  checks (placeholder change on an existing key; shrink-only baseline).
- `scripts/ci/i18n-baseline/key-meta-baseline.txt`: the 3,375 undescribed
  keys. CLAUDE.md rule; ut-docs `reference/translation.md` note.
