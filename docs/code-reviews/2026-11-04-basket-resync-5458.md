# Review: basket re-sync after an outcome-unknown timeout + tile busy state (ut-docs#5458)

Branch `fix/5458-basket-resync`. Follow-up to ut-docs#5404 (ordinary till
actions time out after 30 s). Phases ran as separate agents: BA, Architect
(Opus 5.5), UX design, Dev (Sonnet), Tester, UX §7 gate, and an independent
reviewer (Opus 5.5); the fix round was a fresh Sonnet agent.

## What shipped

- `web/public/app.js`
  - `window.utBasketResync()` re-renders the basket with
    `htmx.ajax('GET','/ui/basket',{source:#basket,…})` and an `X-UT-Resync`
    header. With `#basket` as the source, the re-fetch sits in the same htmx
    sync slot that every tile's `hx-sync="#basket:replace"` uses, so a newer
    tap aborts a late re-fetch. The existing #5411 `ut-basket-resync`
    listener now calls the same helper.
  - The `htmx:timeout` handler schedules a re-sync (`setTimeout 0`, after
    htmx frees the slot) for a timed, non-GET, non-prompt `/api/pos/*`
    request while `#basket` is on the page. The sticky outcome-unknown
    alert stays as before.
  - A generation counter (advanced by every non-resync `#basket` request)
    drops a stale re-sync in `htmx:beforeSwap`, covering basket updates
    that don't use `hx-sync`.
  - A failed re-sync is quiet: `responseError`/`sendError` and the #916
    force-swap return early for re-sync requests.
  - Tile busy state: 300 ms after `htmx:beforeRequest` on a `.btn-tile`
    that is still in flight, `aria-busy="true"` is set; cleared on
    `afterRequest`, `sendAbort`, `timeout` and `sendError`. The tile is not
    disabled.
- `web/public/app.css`: `.btn-tile[aria-busy="true"]` gets a 3px inset
  outline: `var(--focus-border, var(--accent))` on plain tiles, white on
  coloured tiles (the compact ≤480px layout, where coloured tiles have no
  swatch, uses the focus token). A pulse runs only with motion allowed and
  not under `fx-light`; its trough is a 45% mix, never transparent. Logical
  properties only; no layout shift.
- Untouched (another lane works on ut-docs#5454 there): `utPostWithElevation`,
  `utIsPromptElt`, `utIsTimedRequest`, `UT_UNBOUNDED_PATHS`.
- Docs: `docs/sale-screen-notifications.md`; one sentence each in
  `web/help/en/sell.md` and `web/help/de/sell.md` (inside an existing bullet,
  structure unchanged).
- Tests: `e2e/tests/basket-resync-5458.spec.ts` (15 tests).
