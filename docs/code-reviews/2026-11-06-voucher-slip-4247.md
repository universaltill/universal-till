# Review — gift-voucher slip per issued voucher (ut-docs#4247)

Date: 2026-11-06 · Lane: `lane:cloud-54` · Branch: `feat/4247-voucher-slip`
Built by Sonnet; reviewed independently by Opus 5.5 (different model, fresh context, own worktree).

## What shipped
- New per-till printer setting `printer.voucher_slip` (default off; only `"true"` turns it on), saved
  through `POST /api/settings/printer` (elevation re-post, audit field `voucher_slip`). Checkbox
  "Print each gift voucher on its own slip" in Settings → Receipt printer.
- `print.VoucherSlip`, `RenderVoucherSlip` / `RenderVoucherSlipText` (`internal/print/voucher_slip.go`),
  reusing #4224's voucher block (extracted into shared helpers so receipt and slip have one layout).
- `print.PrintDocWithSlips`: the receipt and its slips go out as ONE job (one transport write / one `lp`
  job with form feeds), so no other print lands between them and success/failure stays one flag.
  `PrintDoc` is the nil-slips case, byte-identical to before.
- Slips are added in `printReceiptIn`, the single choke point for every receipt print, so ADR-0124
  suppression and the receipt policy (ADR-0089) gate slips exactly as the receipt. Journal reprints print
  slips again; vouchers voided since the sale and top-ups get none. Slips use the receipt doc's locale and
  charset (kiosk fallback included).
- Help: `web/help/en/printing.md` step 10 + reprint sentence, `vouchers.md`; README voucher paragraph;
  ut-docs `architecture/receipt-printing.md` Scope (separate ut-docs PR).
