# ADR-0002 taxonomy drift: fix + cross-repo guard (ut-docs#2134)

**Date:** 2026-09-12
**Card:** universaltill/ut-docs#2134
**Repos touched:** `ut-docs` (ADR-0002 + related doc fixes), `universal-till`
(this repo — new guard, CI wiring, doc-comment fixes)

## What shipped

ADR-0002 said "20 canonical types" and listed only the original 20, even
though the real taxonomy had grown to 22: `language` was added by ADR-0010
(2026-07-11) and `layout` by ADR-0088 Decision B (2026-09-09) — both real,
accepted ADRs, so ADR-0007's document-first rule was actually followed for
both additions. The defect was narrower than the original card text
suggested: ADR-0002's *own document* was simply never edited to reflect
either amendment, and the mechanism it cited as its guard
(`TestCanonicalTypesMatchTaxonomy`) diffed `internal/plugins.CanonicalTypes`
against a second hardcoded copy of the same list inside its own test file —
structurally incapable of ever seeing the ADR text drift.

Fix:
- `ut-docs/adr/0002-plugin-type-taxonomy.md` edited (not a new superseding
  ADR — nothing here makes a new decision, it only synchronizes the
  document with decisions ADR-0010/ADR-0088 already made and got accepted)
  to the real 22-type taxonomy, with amendment provenance in the status
  line.
- New `scripts/ci/guard-adr-plugin-taxonomy.sh` + its regression test:
  extracts `CanonicalTypes` from the Go source and ADR-0002's taxonomy line
  from a sibling `ut-docs` checkout, fails if they disagree. Mirrors this
  ecosystem's existing `ut-cloud` `manifest-contract-guard` pattern for the
  identical shape of problem (a fact in one repo that must mirror another).
- `TestCanonicalTypesMatchTaxonomy` removed (superseded by the guard above);
  `TestParseManifest_EntryTypeTaxonomy` kept unchanged.
- New standalone `adr-taxonomy-guard` CI job in `.github/workflows/ci.yml`.
- Assorted doc-comment fixes (`CLAUDE.md`, two Go comments, `ut-docs`'s
  `AGENTS.md`/`ECOSYSTEM.md`/`ba`+`dev` skill files, ADR-0050's own
  now-doubly-stale note, `adr/README.md`'s index row) that also asserted
  the stale "20 canonical types" count and would otherwise have
  contradicted the very fix this card ships.
- New follow-up Backlog card (universaltill/ut-docs#2150): auditing every
  other accepted ADR for the same class of doc-vs-code drift — explicitly
  out of scope for this card (BA decision), not silently dropped.

## Independent review (Opus, different model from the Sonnet session that
wrote the code)

First pass found **2 real blockers** and **7 nits**, all fixed in this
same cycle before merge:

- **Blocker — CI job would fail on every run.** `ut-docs` is a *private*
  repo (went private 2026-07-31); the checkout step had no token, and the
  default `GITHUB_TOKEN` cannot read a private repo outside the current
  one. The design's own cited precedent (`manifest-contract-guard`) checks
  out `universal-till`, which is *public* — tokenless works in that
  direction and not in this one. Fixed: `DOCS_READ_TOKEN` secret (same
  convention this file's own `e2e` job already uses for the identical
  problem), with a loud non-blocking skip when it's unavailable (a fork
  PR).
- **Blocker — silent false-pass in the extractor.** The original
  `grep -oE '"[a-z_]+"'` pattern silently *dropped* any quoted value
  containing a digit or uppercase letter (e.g. a hypothetical `oauth2`
  type) instead of failing on it — reproduced live: a 23-type Go fixture
  including `oauth2` against a 22-type ADR reported `agree (22 types)`,
  exit 0. This is exactly the failure class the guard exists to prevent.
  Fixed: extract every quoted string in the block, validate each against
  `^[a-z0-9_]+$` explicitly, hard-fail naming any that don't match. Also
  closed a related gap: a `//` comment containing a quoted word is now
  stripped before extraction, so it can't be mistaken for a real entry.
- Nits fixed: the ADR index (`adr/README.md`) and ADR-0050 both still said
  "20"/"21" and would have directly contradicted the fix on merge; a new
  title-count cross-check (`(N canonical types)` vs. the real count) closes
  a related self-consistency gap the guard didn't originally cover; the
  regression test now runs before/unconditionally relative to the guard
  itself, matching this repo's own established self-test-first convention;
  the merge-order dependency (ut-docs's ADR-0002 PR must land before this
  repo's PR, for the same reason `manifest-contract-guard` documents in its
  own direction) is now spelled out in `CLAUDE.md`; two more stale "20-type"
  code comments fixed.
- Not fixed, deliberately deferred: a handful of accepted-as-loud
  false-*fail* edge cases (the ADR's taxonomy line being re-wrapped,
  re-indented, or a second pipe-list appearing elsewhere in the file) —
  documented in the guard's own header as a known, accepted limitation,
  same convention `guard-compliance-claims.sh` already uses for its own
  detection gaps. A pre-existing, unrelated bug the review noticed in the
  same file (`e2e` job's docs-hub checkout targets `universaltill/docs`,
  not `ut-docs`) was filed separately rather than fixed here, since it
  predates and is unrelated to this change.

Second review round was not needed — no blocker-class (money/tax/data-loss/
security) finding remained after the fixes above, and the fixes were
narrowly scoped to what the first round found, consistent with this
project's "one review round unless the first finds a blocker" rule (the
regex false-pass in a CI guard is analogous in kind to a security-relevant
correctness gap, which is why it got the fixes above rather than being
waved through, but it didn't warrant re-spawning a second independent
read — the fix is small, mechanical, and re-verified directly below).

### TDD re-verification (done personally, not just taken on trust)

Reverted the guard script to its pre-fix `grep -oE '"[a-z_]+"'` form,
re-ran the regression suite: the new case 6 (`oauth2` in the Go fixture)
failed to catch the drift — the guard passed when it should have failed,
reproducing the exact bug the review found. Restored the fix; all 8 cases
pass. Also independently reproduced the reviewer's own revert-then-restore
check on ADR-0002 itself: reverting the ADR to its pre-fix text makes the
guard fail naming `language`/`layout` as the drift; restoring it passes
again.
