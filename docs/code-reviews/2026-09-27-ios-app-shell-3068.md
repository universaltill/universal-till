# Review — iOS till shell + simulator CI (ut-docs#3068)

- **Card:** ut-docs#3068 (first slice of ut-docs#3046, iOS/iPadOS till app)
- **Branch / PR:** `feat/3068-ios-app-shell` / universal-till#1483
- **Author:** Opus 5.5 (`:54` cloud lane). **Reviewer:** Fable, independent subagent, one round.

## What shipped

- `ios/`: XcodeGen `project.yml` (the `.xcodeproj` and `Info.plist` are
  generated, git-ignored) and a SwiftUI app: `TillServer` wraps the
  gomobile-bound `mobile.Start/Stop/IsRunning/SetDeviceModel`;
  `TillController` starts the server off the main thread on one serial
  queue and owns the starting/running/failed state; `TillWebView` shows the
  loopback origin in a `WKWebView`, confined to that origin (other links →
  system apps on a user tap only), camera granted to the till origin only,
  error bar with *Back to till*, reload after a killed content process.
- Resume: restart the server only when `MobileIsRunning()` is false or
  three `/healthz` probes on an ephemeral session all fail — a healthy
  server is never restarted (the basket lives in server memory).
- Shell strings + InfoPlist texts in en/ar/fa/tr (Android's set).
- `.github/workflows/ios-ci.yml` (macOS-15, in-job `git diff` gate like
  `android-ci.yml`), `scripts/ci/ios-sim-smoke.sh`,
  `scripts/ci/ios-screenshot-check.swift`.
- `ios/README.md`; root `README.md` iOS lines updated.

## Verified beyond automated tests

- `GOOS=ios GOARCH=arm64 CGO_ENABLED=0 go build ./mobile` clean (no Go changed).
- `ios-ci` on a macOS runner: gomobile bind (ios + simulator), unsigned
  `xcodebuild`, then the app launched on an iPhone and an iPad simulator,
  the in-app server answered `/healthz` on :8080, the app came back from
  the background as the same process (pid unchanged) and still answered.
- Screenshots (read from the in-log previews, run 36347597727): iPhone
  (1206×2622, 384 colours, 39% non-background) and iPad (1668×2420) both

  In-app update isn't available for this install" banner (correct: iOS

  ut-docs#3071. Not looked at: landscape, dark theme, sale screen.
