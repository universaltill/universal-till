# Review — a 402 that closes the gate keeps the normal tick cadence (ut-docs#4304)

**Date:** 2026-10-14 · **Lane:** lane:cloud-54 · **Written by:** Opus 5.5 · **Reviewed by:** Sonnet (fresh-context subagent).

## What changed

After an unpaid check-in answered 402 `plan_required` (start-up check-in, operator window, and with #4285 the hourly renewal watch), the scheduler honoured `Retry-After: 3600`, so the local work at the top of every tick — issue-report and diagnostics uploads — waited up to an hour. Option (a) of the card:

- `tick` wraps a 402 in `gatedRefusal` (`markGatedRefusal`) at both 402 returns (conditional GET and the unpaid POST) when, with its block cached, `syncAllowedFn` now says no.
- `scheduler.next` treats a gated refusal like a quiet tick: failure streak reset, normal jittered cadence; ADR-0116 D6's lock-out wait still wins.
- A bare 402 (block missing or cache still paid — cloud and cache disagree) keeps honouring Retry-After, so no 2-minute retry loop against the cloud.
- `logTickError` names Retry-After only for a bare 402.
- ADR-0148 (§4 of the 2026-10-05 amendment, §2 of the 2026-10-14 one) updated in ut-docs to say the same.

The wrapper has `Unwrap`; every consumer of the tick error (`planRequired`, `retryAfterHint`, `authTracker.observe`, `AfterTick` hooks) uses `errors.As` or only `err == nil`.

## Tests (TDD)

- `TestSchedulerKeepsNormalCadenceAfterAGated402` — wait within one jittered tick, streak reset, no chip, `errors.As` through the wrapper.
- `TestTickGated402UploadsAnIssueReportWithinOneNormalTick` — real gate, paid cache, cloud 402s: wait 2m (was 1h), the next tick uploads a newly saved issue report with zero sync calls (the card's AC).
- `TestTickUnpaidCheckin402IsMarkedGated` — the unpaid POST path (operator window on a lapsed till).
- `TestMarkGatedRefusalOnlyWhenTheGateIsClosed` — open gate stays bare, 503 never marked.

Verified failing first: with the scheduler branch disabled both cadence tests fail with `wait 1h0m0s`; with the POST-site `markGatedRefusal` removed the unpaid test fails. `go test ./internal/cloudsync/ ./internal/pages/` green; `golangci-lint` 0 issues; guards data-access, core-neutral, netaccess, kiosk-engine, demo-env, page-http-error, card-data-schema pass (deadcode-baseline can't run locally: tool built with an older Go — CI runs it).
