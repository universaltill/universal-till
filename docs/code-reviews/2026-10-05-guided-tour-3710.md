# Review — guided sale-screen tour (ut-docs#3710)

**Date:** 2026-10-05 · **Author:** Opus 5.5 (dev subagent) · **Reviewer:** Fable 5.1 (independent, read-only)

## What shipped
- `web/public/tour.js` — own tour engine (no library): anchored balloon with arrow, highlight ring, visual-only backdrop (`pointer-events: none`, status bar / Lock / exit stay reachable), Back / Next / Done / Skip, "n / N", keyboard (Enter/→, ←, Esc; mirrored in RTL), focus to Next, viewport clamping, resize/orientation/scroll reposition, skips hidden/missing targets, never starts over a dialog/scrim.
- `web/ui/partials/tour.html` (included by `index.html`) — 11 steps as JSON built from `tour.*` keys.
- `internal/pages/tour.go` — `POST /api/tour/done` (session user only; 401 anonymous); index sets auto-start when `tour.done.<userID>` is unset; `/?tour=1` restarts; self-order kiosk redirects before the tour renders.
- Help: new `guided-tour` topic (en/de/ar/fa/tr); "Take the tour" on Help home + Selling topic.
- 31 `tour.*` keys in en/ar/fa/tr; DE/ES via language-pack follow-up PRs.
- e2e helpers mark the tour done for auth-project users so existing specs are unaffected.
