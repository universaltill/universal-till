# Review — main-till link, replica side: `fleetlink.Client`, pull-loop floor, shared PrimaryWatch (ut-docs#2735)

- **Author:** Opus 5.5 (Dev subagent). **Reviewer:** Fable 5.1, fresh context, worktree `feat/2735-replica-link-client`, one round. Card p1, complexity:medium.
- **Binding design:** ADR-0114 §2–§4, §8, §11 (task 2 of its breakdown). Main side is #2734 (`2026-09-25-main-till-link-2734.md`); §7 TLS is #2736.

## What shipped
1. **`fleetlink.Client`** (`client.go`): dials `GET /api/sync/link` only when `GET /api/sync/ping` advertises `link ≥ 1` (§11; an older main till is polled as before), bearer in the upgrade request's `Authorization` header only, redirects never followed, `ReadLimit` applied on the dialled side. Full-jitter backoff 1 s → 30 s (§4), `Retry-After` honoured on 503, 4001 (replaced) backs off 15–30 s instead of fighting, 4003 / HTTP 401 / 403 pin `revokedFor` to the exact `Target` (URL + bearer) so dialling stops until the pairing changes, `bye` on shutdown. `Redial()` and a 30 s re-check both re-read the target. Three goroutines at most (Run + Peer reader/writer); every `runLink` exit joins the Peer before the next dial.
2. **`Peer` split into `peerHost`** (`peer.go`, `hub.go`): the one reader/writer/queue implementation now serves both sides; `Hub` and `Client` differ only in hello, request handlers and which one-directional frames they accept. `readErr` / `peerBye` carry why a link ended. Dialled links skip the close handshake on `CloseGone`.
3. **Replica wiring** (`sync_link_client.go`): target/probe/hello/report from settings at call time; hello = `primaryContactOK` and a pull kick when any cursor differs; `sync` nudge = pull kick; lost link = `primaryContactFailed`; re-discovery's switch calls `LinkClient.Redial()` (§4). `Deps.LinkClient`, `Deps.SyncPullNow`, `Deps.RequestSyncPull` (cap-1, coalesced, nil-safe).
4. **Pull loop** (`sync_admin.go`): `runPullLoop` replaces `runSyncLoop` for the admin pull — 30 s unlinked, 5 min linked (§3), at once on a kick, and a link drop re-arms the short interval measured from the last tick. Unlinked behaviour is unchanged (first tick at 30 s, coalesced kick, `ctx` exit).
5. Deadcode baseline burns down five `fleetlink` entries the client now reaches.

## Verified beyond the automated tests
- **Goroutines / reconnect leaks:** `Run` owns one goroutine; `runLink` starts the Peer (reader + writer) and every exit path — `ctx`, `done`, retarget, redial — waits `<-done` before returning, so a previous link is fully joined before the next dial; `wait`'s timer is stopped; `startClient` proves `Run` returns on cancel. `CloseGone` on the dialled side is `CloseNow`, so a silent main till costs no 5 s handshake before the redial.
- **Bearer:** header only, in both the probe and the upgrade; `linkURL` strips query and fragment; `DialError` carries the status alone; log lines carry till id, version and status.
- **Redirects:** both HTTP clients use `ErrUseLastResponse`; a 3xx surfaces as `DialError{3xx}` and backs off — never followed, so the bearer reaches the configured host only.
- **Revoked → stop:** three entry points (probe 401, dial 401/403, close 4003) converge on `markRevoked`; `OnRevoked` fires once per pairing; only a changed `Target` dials again (test: re-pairing with a new bearer relinks).
- **4001:** the client's own stale half-open link is abandoned before it redials, so self-replacement is not a fight; two devices sharing one bearer ping-pong at 15–30 s, which is §1's "a new one closes the old".
- **Redial vs running dial:** `redial` is a cap-1 channel drained in `wait` and in `runLink`; a poke during probe/dial is consumed by `runLink`'s redial arm, which compares targets and is a no-op when unchanged (test: the switch is also noticed on the plain re-check).
- **Offline-first:** nothing on a sale path touches `LinkClient`; callbacks run on the client goroutine; `Report`'s queue-depth count is off the request path.
- **Memory:** cap-1 channels, a `uint32` scope mask, the report compared by value; inbound hello strings clipped by `Peer`; `ReadLimit` set on the dialled conn.
- **Unlinked pull loop:** 30 s, first tick at 30 s, coalesced kick, `ctx` exit — `TestSyncPullLoop_*` pin it; a main/standalone till's client idles on `RecheckEvery` and never dials (test).
- **Android:** `GOOS=android GOARCH=arm64 CGO_ENABLED=0 go build ./internal/fleetlink/ ./internal/pages/common/` and `go vet ./internal/pages/ ./internal/pages/catalog/` pass.
- **TDD claims re-verified by the reviewer** (revert → red → restore → green, one command each, sequentially): findings 1–5 above, each with the quoted failure.
