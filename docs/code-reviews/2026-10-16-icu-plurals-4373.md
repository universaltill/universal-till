# 2026-10-16 — ICU MessageFormat subset: plurals in the till (ut-docs#4373)

ADR-0160 §8, task 12. Lane `lane:cloud-41`, built on Opus 5.5.

## What shipped

- `internal/msgfmt` — an ICU MessageFormat subset: `{name}`,
  `{n, number[, integer]}`, `{n, plural, [offset:N] =N {…} one {…} other {…}}`
  with CLDR cardinal categories (zero/one/two/few/many/other, from
  `golang.org/x/text/feature/plural` with UTS #35 operands), `#`,
  `{k, select, … other {…}}`, nesting, ICU-default apostrophe quoting.
  Everything else (selectordinal, dates, a missing `other`, unbalanced
  braces, unterminated quotes, a missing argument) is an error.
- `config.I18n.TM(locale, key, args, opts)` — resolves like `T`
  (`T` now shares `resolveLocked`, same chain and shop > base > overlay
  precedence), formats with the plural rules of the locale the value came
  from, and on any error falls back to the English value; if English fails
  too, its raw text renders (never a blank). Unknown key → the key.
- `{{ TM "key" "name" value … }}` template func and `httpx.TM` for Go;
  numbers are grouped and digit-shaped for the request locale like
  `{{ qty }}` (fa/ar get ۳ / ٣).
- `guard-i18n.sh` check 1 also validates `{{ TM "key" }}` keys; self-test
  case added. A Go test makes every shipped locale value of a
  plural/select key parse (a broken translation would otherwise ship
  silently as English).
- ut-docs `reference/translation.md`: a "Plurals — MessageFormat keys"
  section (categories, keep argument names, apostrophes, how to call it,
  move `%d` keys one at a time as new keys).

No new locale keys; no UI surface changed, so no UX pass or manual update.
