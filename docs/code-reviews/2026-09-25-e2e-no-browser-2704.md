- **Author:** Opus 5.5 (lane:local session). **Reviewer:** Sonnet 5, fresh context (card is complexity:easy; reviewer ≠ author).

## Findings
1. **HIGH, fixed:** `e2e/tests/worker-till.ts` spawns the default project's per-worker tills (most of the suite) without `UT_OPEN_BROWSER`, and the first guard only scanned `*.sh`. Fixed the spawner; the guard now scans `*.sh` + `*.ts` under `e2e/` (node_modules pruned). Proven: the guard fails on the pre-fix `worker-till.ts` (exit 1).
2. **LOW, fixed:** the guard only accepted a literal `0`; `strconv.ParseBool` also takes `false`. Both are accepted now (test case added).
3. **Info, left:** legacy `tests/e2e/README.md` tells a developer to run `go run .` by hand. That's an interactive run where a browser is wanted, so it's out of scope.
4. Own finding, fixed: a failing `find` inside the loop's input would have passed silently. The guard now exits 2 on a missing dir or zero launchers.

## Checked, no issue
Env inheritance into the exec'd binary in all 5 scripts (no `env -i`/subshell); `internal/app/*_test.go` already set `UT_OPEN_BROWSER=false`; every Playwright `webServer` command goes through a covered script; ci.yml steps sit in the unconditional build job; shellcheck clean.
