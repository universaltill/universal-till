# Review: move macOS CI jobs off the retired macos-14 image (ut-docs#5214)

**Date:** 2026-10-30 · **Lane:** lane:cloud-41 · **Branch:** `fix/5214-macos-14-retired`
**Author:** Sonnet subagent (Dev) · **Reviewer:** Opus 5.5, separate subagent (different model)

## What shipped

- `desktop-darwin.yml` and `release.yml`'s `macos-app` job: `macos-14` → `macos-15`
  (Apple Silicon). GitHub retires macos-14 on 2026-11-02, and the scheduled
  brownouts already cancel every `desktop-darwin` run 2 seconds in.
- `packaging/macos/build-app.sh`: exports `MACOSX_DEPLOYMENT_TARGET`, read from
  Info.plist's `LSMinimumSystemVersion` (13.0), for the cgo `unitill-desktop`
  build. Without it, clang uses the runner SDK's macOS as the target, so the
  newer image would silently raise the binary's minimum macOS. After the build,
  `vtool -show-build` checks that `minos` equals the target, and the build
  fails if it doesn't.
- New `scripts/ci/guard-retired-runner-images.sh` and its sandboxed `_test.sh`,
  wired into `ci.yml`'s build job. The guard fails when a workflow names a
  retired hosted image as a value: `macos-13`, `macos-14`, `ubuntu-20.04`,
  `windows-2019`, and their `-large`/`-xlarge` variants. Comments are ignored,
  so the historical notes stay.
- Docs updated: `CLAUDE.md` (desktop-darwin line) and `docs/arch/desktop-app.md`.

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| 1 | minor | The guard treated `macos-14-large`/`-xlarge` as live, and the test pinned that. GitHub retires those variants with the base image. | Fixed: the guard matches the variants, and the test now expects them to fail. |
| 2 | minor | Nothing checked that the deployment target took effect. A forced internal linker or an env override would silently raise the minimum again. | Fixed: `build-app.sh` checks minos with `vtool` after the build. |
| 3 | nit | `desktop-darwin.yml` compiles without the deployment target. | Accepted: that job is only a compile/vet check. |
| 4 | accepted | The guard also flags a retired label inside `run:`/`if:` text, and misses a label after a `#` inside a quoted `${{ }}`. | Accepted: the first fails closed and has no hits today; the second is rare. |

The reviewer confirmed these points:
- clang honours `MACOSX_DEPLOYMENT_TARGET` for both compile and link.
- `plutil -extract … raw` exists on macOS 12 and later.
- The export comes after the `CGO_ENABLED=0` build, so that binary is unaffected.
- The macos-14 mentions left are history comments only.

- The guard's `_test.sh` passes 11 of 11 cases, and `shellcheck scripts/ci/*.sh

  `guard-ci-tests-sandboxed`, `release-macos-nonblocking_test` and

  and its minos check first run at the next release, or by `workflow_dispatch`
