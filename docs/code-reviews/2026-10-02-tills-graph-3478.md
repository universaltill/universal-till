## What shipped
- **Till:** every check-in carries `peripherals` (≤ 32, sorted, deduped):
  receipt printer (connection from the address shape), kitchen printers
  (one per physical printer), paired Bluetooth devices (3 s bounded lookup;
  a paired keyboard reports as a scanner), the fiscal device (via the
  neutral `fiscal.device` capability). No addresses, MACs, paths or serials;
  a name that is an address is blanked; names ≤ 64 runes. Core-neutral
  guard passes; no payment-plugin code in core.
- **ut-cloud:** the sync report's typed `peripherals` (absent keeps the last
  report, `[]` replaces), validated and coerced (unknown kind → other,
  status → unknown, connection dropped), stored in the device metadata (no
  schema change); manage-payload tills carry them; new `GET /ui/app/fleet`
  (signed-in owner's own undeleted shops, same scope as the store picker;
  ≤ 50 shops × 50 tills × 32 devices with `truncated` flags; `no-store`).
- **my.:** List | Graph switch at the top of Tills (remembered per browser,
  storage failures tolerated); graph = account → shops → tills → devices
  as an ARIA tree (arrows, Home/End, RTL-mirrored Left/Right, Space
  toggles, Enter opens a till or switches shop), status as dot + text,
  Expand/Collapse all, horizontal on desktop, vertical under 600 px; the
  single-till panel lists its devices. Device glyphs drawn from inlined
  paths (no new dependency). 36 keys in all 10 locales.
