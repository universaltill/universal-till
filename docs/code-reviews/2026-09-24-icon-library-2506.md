# Code review — built-in icon library, first cut (ut-docs#2506)

Date: 2026-09-24 · Branch: `feat/2506-icon-library` · Lane: cloud-24
Author model: Opus 5.5 · Reviewer: Fable (independent subagent, isolated worktree)

## What shipped

- **~72 built-in icons** (was 5): hot drinks, cold drinks, bar (beer, wine,
  cocktail, spirits, sparkling wine), bakery, food, fruit & veg, sweets,
  general (tag, gift, bag, box, star, offer, vegan, gluten-free). Registry:
  `internal/catimport/icons.go`. Sources are vendored upstream SVGs in
  `internal/catimport/iconsrc/{lucide,tabler}/` with their LICENSE files
  (Lucide ISC, Tabler MIT). Each tile names its source + licence in a comment.
- **Tiles are generated**, never hand-edited: `icons_render_test.go` renders
  64×64 tiles (group background + dark stroke, because `<img>` can't inherit
  `currentColor`). `TestCategoryIconTiles_InSync` fails on any drift;
  `UPDATE_CATEGORY_ICONS=1` regenerates. The generator is in a `_test.go`
  file so the shipped binary has no unreachable code (deadcode guard).
- **Stored paths stay compatible**: `coffee/drink/sandwich/pastry/generic`
  keep their filenames. The four food tiles get the new style; `generic`
  stays hand-drawn.
- **Pickers** (item image tab, category editor): grouped sections, "No image"
  first, a scroll box (18rem), and a search box (`web/public/icon-picker-filter.js`,
  shared and delegated) that matches the translated label plus English
  keywords.
- **Auto-suggest / import** (`placeholder.go`): specific icons for the new
  set. Two-word keywords ("hot dog", "hot chocolate", "ginger beer") and
  s/es plurals ("Sandwiches", "Cakes") are both matched whole-word only.
- i18n: 77 keys in en/ar/fa/tr (de/es in the pack PRs). Help text updated
  in 5 languages (catalog + categories).
