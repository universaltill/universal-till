# Code review: EOD tab on-screen Tips total (ut-docs#1529)

**Date:** 2026-09-08
**Card:** ut-docs#1529 (`complexity:easy`)
**Diff:** `internal/pages/reports_page.go`, `internal/pages/reports_page_test.go`,
`web/ui/partials/reports_tab_eod.html`, `web/locales/{en,ar,fa,tr}.json`,
`web/help/en/reports.md`, `web/help/img/manifest.json`,
`web/help/img/{ar,en}/sell.png`

## What shipped

`EODReport.Tips` (ut-docs#1007) was already broken out by payment method and
held out of revenue on the printed Z-report (`buildEODDoc`'s "TIPS (held out
of revenue)" footer, `internal/pages/eod_api.go`) and in the downloaded JSON
(`POST /api/reports/eod/range`), but the on-screen Reports tab's day-row
table (`web/ui/partials/reports_tab_eod.html`, backed by
`internal/pages/reports_page.go`'s `"eod"` tab case) showed only Sales/Net —
a manager glancing at the tab without printing or downloading had no
visibility into tips at all.

The fix adds a `Tips int64` field to the tab's local `eodRow` view-model
struct, summed from `rep.Tips[].Amount` (each report's own
`[]data.EODTip{Method,Count,Amount}`), gated behind `canRunEOD` exactly like
Net/Sales — it is a real money figure from the same report history. The
template gains a `Tips` column header and cell next to Sales/Net, and the
nested article/operator/order-type breakdown row's `colspan` is bumped from
4 to 5 in the `canRunEOD` branch only (the non-`canRunEOD` branch stays at 2
— unchanged, it never had the extra columns).

A `reports.eod.tips` locale key ("Tips") was added to all four shipped
locale files. The self-hosted Ollama NAS this project normally translates
through (`reference/translation.md`, `192.168.1.231:11434`) is unreachable
from this cloud sandbox (confirmed: a direct `curl` to it timed out) — so
rather than fabricate new translated text, the ar/fa/tr values reuse the
exact, already-shipped translation of the same word from the existing
`reports.tab.tips` key (a tab label meaning "Tips" in the same product
area): fa `انعام‌ها`, ar `الإكراميات`, tr `Bahşişler`.

`web/help/en/reports.md` gained one sentence, in the existing paragraph
about the printed report's tips line, noting the same total now also shows
on-screen. Only English was updated, for the same translation-unreachable
reason. `web/help/img/manifest.json` plus `sell.png` (ar/en, 1 byte each)
were regenerated by `make docs-shots` (this repo's pre-installed-Chromium
path, built for exactly this kind of cloud session) — the `reports` topic's
own screenshot did not need to change (see below).
