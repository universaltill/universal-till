# Code review — phone layout sweep (ut-docs#3297)

**Date:** 2026-10-01 · **Branch:** `fix/3297-phone-layout-sweep` · **Reviewer:** independent subagent (Fable 5.1; code written by Opus 5.5)

## What shipped
The product owner walked the iPhone app (440 CSS px, TestFlight v0.30.11) and sent nine screenshots. An automated pass over every GET route at 360×740 and 440×956 (touch emulation) found the rest.

- **☰ drawer** (`app.css` phone block, `bugreport_chip.html`): the session chip's old one-row top-bar override is deleted, so a manager's Users / Promotions / Translations / name / Lock are full-width labelled rows. The bug-report label is a `.nav-toggle-label` (hidden in the rail, shown in the drawer).
- **/items section list**: `.items-rail-wrap` is no longer sticky once the panes stack (≤52rem), so the catalog stops scrolling under it. This was also the owner's own bug report ("when scroll the down part goes under tree view").
- **Pages scrolling sideways** (inventory, translations, audit, shifts, tills, journal, plugins, receipt designer): at ≤480px, wide data tables (`table.table`, `.card table`, `table.translations-grid`) scroll inside their own box, following the `.users-list .table` precedent. Tables that already have a scroll wrapper and the basket table are excluded. Fields are capped at their container, `.field-checks` rows wrap (all widths), and the Plugins toolbar wraps.
- **Basket sheet**: − qty + on one row, with the discount box after them. In the open sheet the ✕ moves up beside the item name, so the second row fits at 360px. A zero discount renders blank, so the translated "Disc." placeholder shows instead of an unexplained "0" (`/api/pos/line` reads empty as 0).
- **Dine in / Takeaway**: `hyphens: manual` + `overflow-wrap: break-word` ("Takeaw ay" was `hyphens: auto` on a squeezed segment).
- Manual: `web/help/*/sell.md` "Selling on a phone" describes the new basket row (en/de/ar/fa/tr). Screenshots regenerated (`make docs-shots`).
