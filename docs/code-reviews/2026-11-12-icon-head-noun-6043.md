# Review: icon auto-suggest matches a compound's main noun when the language says it comes last (ut-docs#6043)

**Change.** German compounds put the main noun last (Milch*kaffee*, Apfel*saft*,
Weiß*bier*), so the whole-word icon matcher left them generic. A language can
now switch on a head-noun step by translating the new key
`catalog.icon_match.head_last` as `1` (ADR-0160 §12, ut-docs#6141). Core tests
no locale code.

- `internal/catimport/placeholder_lang.go`: `Icon` tries, in order, the strict
  match on the name across every pass (English in its place), the strict match
  on the category, the head-noun step on the name, the head-noun step on the
  category, then `generic`. Head-noun step: the word ends with a single-word
  label of at least 3 runes, with at least 4 runes before it (counted after
  normalisation). The longest label wins. It runs only for passes whose
  language set the key to exactly `1`, after trimming.
- `web/locales/en.json` gets `catalog.icon_match.head_last` = `"0"`, and
  `web/i18n-meta/en.meta.json` describes it as "Setting, never shown on
  screen". The description says to leave it at 0 unless a maintainer has
  measured the language, and that only ASCII `1` switches it on.
  `max_length` is 1.
- `web/help/en/catalog.md`: the line that used to say Milchkaffee isn't
  recognised now describes the behaviour and its limits. The docs-shots
  manifest gets the catalog topic hash. The screenshot shows the catalog page
  UI, not the help text, so no pixel changes.
- `internal/data/setting_scope_test.go`: `catimport.headLastKey` is exempted.
  It is an i18n key, not a setting key.

## Measurement (the card's acceptance criterion)

The sample is 182 German shop item names. It includes traps: Schwein/Wein,
Preis and Kreis/Reis, Bierglas, Eistee, Kaffeetasse. The real `IconMatcher`
ran with the de pack's labels and the key set to `1`, name only:

| min label / min modifier (runes) | new hits | wrong |
|---|---|---|
| 4/1 | 77 | Schwein→wine, Preis/Kreis→noodles |
| 4/4 | 67 | 2 |
| **3/4 (shipped)** | **73** | **2 (2.7 %)**: Apfeltasche→bag, Leberkäse→cheese |
| 5/4 | 40 | loses Saft, Bier, Brot |

- Before this change, every name that now gets an icon was generic. No trap
  name changed.
- With the key absent, `0`, `true` or `yes`, the output is identical to `main`
  for all 182 names. A made-up locale gives the same results, which shows the
  rule doesn't depend on the locale code.
- Since the review's tier fix, a category such as Kuchen or Fleisch corrects
  the two wrong hits.
- An adversarial set of 50 names showed known wrong classes: -preis→noodles,
  Sparschwein→wine, Flammkuchen→cake. No length rule fixes them. The icon is
  a dashed-outline suggestion that one tap replaces, so they become a
  follow-up card.
- No real German catalogue export was available, so the measurement on one
  is a follow-up card.

## Review

The author was a Sonnet Dev agent. The reviewer was Opus 5.5 with fresh
context, followed by a re-verification of the fixes (also Opus 5.5). The
Tester was a separate agent.

1. **High, fixed.** The head-noun step ran inside each language pass, so a weak
   suffix hit beat a later strong hit. "Kinderpreis Cola" went can→noodles,
   and Apfeltasche in category Kuchen went cake→bag. Matching is now tiered as
   described above, and `TestHeadLast_StrictBeatsHead` pins it. That test
   fails on the pre-fix code (bag, noodles, noodles, coffee) and passes now.
2. **Low, fixed.** The help text implied short-modifier words get a wrong
   icon. They actually keep the generic or department icon. Reworded.
3. **Low, fixed.** `headWordMatches` now checks `HasSuffix` first and counts
   with `utf8.RuneCountInString`, so it doesn't allocate.
4. **Low, fixed.** The meta description now tells translators to leave the key
   at 0 unless a maintainer has measured their language. Arabic-Indic digits
   leave it off (fails safe).
5. **Nit, fixed.** Wrong head word named in two test comments.
6. **Nit, accepted.** `anyHeadLast()` rescans the passes on each call (a few
   entries, negligible).

TDD re-verified independently. The Tester and the reviewer each swapped in the
pre-change `placeholder_lang.go` with `go test -overlay`. `TestHeadLast_MustHit`,
`LocaleNeutral`, `ExistingHitWins` and `LongestLabelWins` fail there; `OffByDefault`
and `Traps` pass there by design, because they pin `main`'s behaviour. The
Tester also drove the real path, `common.ShopIconMatcher` →
`httpx.TExact` → `config.I18n`: Milchkaffee→coffee with de `1`, generic with
`0` or the key absent.

Gate: `gofmt -l .` empty, `go build ./...`, `go vet`, `golangci-lint run ./...`
0 issues. `go test` passes for catimport, config, data (the Setting/Scope
tests) and web. All `ci.yml` build guards pass locally, except
deadcode-baseline (the container's deadcode is built with go1.26) and
shellcheck-version (no shellcheck installed); both are environmental.
`go test ./...` could not finish here: `internal/plugins` hangs past 10 min on
`main` too. Under `-race`, `internal/data` timed out in
`TestEnsureDefaultThumbnailConcurrentRace`, which this change does not touch.
CI runs both.

**Verdict:** ship.
