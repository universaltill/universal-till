# Code review — page navigation zoom from the tapped element (ut-docs#2942, ADR-0122 §2–3)

- **Date:** 2026-09-26
- **Branch:** `feat/2942-page-zoom`
- **Author:** Opus 5.5 dev subagent (lane:cloud-24). **Reviewer:** Fable, a different model, working in an isolated worktree.

## What shipped
- **Origin recorder** (ADR-0122 §2) in `base.html`'s first script:
  - A capture-phase `pointerdown` listener, plus `keydown` Enter/Space, sets `UT.motionOrigin = {rect, el, at}` from the nearest interactive ancestor.
  - `UT.takeOrigin()` hands the origin out once and clears it. The next press replaces it, and it expires after 5 s.
  - An off-screen or zero-size element counts as no origin. Nothing here can throw.
  - The recorder is defined before the View Transition feature gate, so #2943 and #2944 can reuse it.
- **Page zoom** (§3) replaces ADR-0118's push:
  - The keyframes `ut-page-zoom-in` and `ut-page-zoom-out` read `--ut-zoom-x/-y/-s`, which are set on `<html>` in `htmx:beforeTransition` (boosted navigation) and `pagereveal` (cross-document).
  - `ut-page-recede` / `ut-page-return`, the black backdrop and the fixed rail/statusbar groups are unchanged.
  - The fallback is bottom centre at scale .3.
  - `--ut-nav-dir` is removed; it had no consumer left.
- **Back store:** `sessionStorage` key `ut-zoom-back` holds entries `[to, from, l, t, w, h]`, newest 20, validated on read, every access in try/catch. A pop shrinks into the stored box only when it lands on `from`.
- **Light / reduced motion:** unchanged gating. JS returns before any `zoomTo`, and the CSS backstop `animation: none` already covers `::view-transition-*(*)`.
- **Tests:**
  - Go static guards rewritten: `TestAppCSSPageMotionIsTheZoomFromTheOrigin`, `TestAppCSSPageZoomNeedsNoDirectionVariable`, `TestBaseHTMLRecordsTheMotionOrigin`, `TestBaseHTMLZoomOriginAndBackStore`.
  - New e2e `e2e/tests/page-zoom-2942.spec.ts` (10 tests). It covers Full, where the first-frame matrix is uniform and matches the tile box within 2 px; back into the stored box; the fallback; keyboard activation; 360 px; RTL `fa`; the cross-document reveal; the store cap; Light (no VT and no transform animation for 1.5 s); and a mouse and touch tap mid-zoom.
  - Existing 2223, 2496 and 2859 specs updated.
- **Help:** "page slide" became "page zoom" in the `display` topic in en/fa/tr/ar; the de text already said "Seitenwechsel".
