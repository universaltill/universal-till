# Review: settings-write guard by store type (ut-docs#2999)

- **Branch:** `fix/2999-settings-write-guard-store-type`
- **Author:** Opus 5.5 (lane:cloud-24)
- **Reviewer:** Fable, an independent subagent in its own detached worktree

## Scope

ut-docs#2979's source-scan guard (`internal/pages/settings_write_guard_test.go`)
only recognised `<x>.Settings.Set/SetMany`, `common.SaveState` and the
barcode setters. Shop-wide writes through any other receiver stayed local on
an additional till, where the next admin pull (main-till-wins) silently
reverts them. Acceptance: extend the guard to any settings-store write (the
store's type, not the field name), route or annotate each finding, add
fixtures for the new shapes.

## What shipped

- **Guard** — syntactic receiver typing: `<x>.Settings`; parameters
  (closures' included), variables and struct fields typed `*settings.Store`
  under any import alias; names assigned from a store expression (chained);
  values of a package interface with `Set`/`SetMany` (e.g. `settingsKV`).
  `internal/pages/common`'s helpers are scanned too. Per-till constant keys
  and `// settings-write:allow <reason>` keep working. A second fixture file
  covers each new shape plus non-store `Set` calls (`Header().Set`, another
  cache type) that must not be flagged.
- **Findings, each routed or annotated:**
  - `menu_layout_settings_page.go` restore/re-hide (`menu.restored_keys`,
    shop-wide) → `saveShopSettings` (write-through). `common.SaveRestoredMenuKeys`
    replaced by the pure `common.EncodeRestoredMenuKeys`; a write-through
    refusal redirects to `/settings/menu?err=settings.error.*` (allow-listed,
    rendered through `T`; existing keys, no new strings).
  - `locale_generation.go` `retireLocaleOverrides` → annotated: main till /
    pre-join only; every follower path sends the bump with the locale
    (ut-docs#2948). Closed the one follower path that could still bump
    locally (Store card, failed generation read): `else if !follows`.
  - `fiscal_api.go` signing-override grant → annotated as a known gap; the
    main-till apply refuses a non-empty override, so the fix is a design
    call, filed as **ut-docs#3808** (recommended default: refuse on an
    additional till).
  - `common.SaveState`'s own `SetMany` → annotated (the helper; callers are
    guarded by name).
- **Review fix (finding 1):** `newRederiveSettings` (the hook the main-till
  apply, the replica pull and cloud directives share) now calls
  `ReloadMenuAmendments`, so a restore that arrives as a settings row reaches
  the cached Menu, not only the store.
- **Help:** `web/help/{en,de,tr,fa,ar}/multitill.md` item 13 lists restoring
  or re-hiding a tile under Settings → Hidden menu tiles among the
  shop-wide changes sent to the main till. `web/help/img/manifest.json`
  regenerated by `make docs-shots`; the PNGs it rewrote were reverted — this
  change alters no rendered page (help prose and backend logic only), and the
  diffs were this container's font rendering.

## Findings

1. **Medium — fixed.** A follower's restore landed in the main till's store
   but the main till's Menu kept hiding the tile (`MenuAmendments` is a cache
   rebuilt only at boot, plugin reload and the local handler). Fixed in
   `newRederiveSettings`; new test
   `TestRederiveSettings_RebuildsMenuAmendmentsFromRestoredKeys` (failed
   before the fix, passes after). Also fixes the pre-existing pull-side gap.
2. **Low — accepted.** Store-typed struct fields are tracked by name per
   package, so a same-named non-store field's `Set` would be flagged. No such
   case exists; an allow tag resolves it. Documented as syntactic.
3. **Low — accepted, documented.** Known false negatives: package-level
   closures, multi-value assigns, a store from a function return/map/package
   variable. None exist in `internal/pages` today.
4. **Info — checked OK:** elevation shape matches `update_api.go`'s
   `saveShopSettings` caller; the `?err` allow-list covers every
   `settingsSyncMessageKey` value; the main-till locale path is unchanged;
   help translations natural and match each locale's page title.

## Verification

- `go build ./...`, `go vet`, `gofmt -l` clean; `go test ./...`; every

  (no `shellcheck` binary in this container; no shell script touched).
- `golangci-lint` not runnable here (binary/toolchain mismatch); the removed

## Verdict

Safe to merge. Deferred: ut-docs#3808 (fiscal override on an additional till).
