# Review: `tools/wasmbench` — WASM cost harness (ut-docs#3153)

**Shipped:** `tools/wasmbench/` — a CLI + `build.sh` that time per-event
instantiation of WASI command modules vs. calls into a `c-shared` +
`//go:wasmexport` reactor, under wazero's interpreter and compiler, with the
till's runtime settings (CloseOnContextDone, 1024-page memory limit, 2 s
per-event deadline context). Guests: `guests/command`, `guests/reactor`
(wasip1-only), shared handler `guests/answer`. Results and verdict live in
ut-docs `architecture/wasm-runtime.md` § *Measured cost*. No production code
changed.

**Reviewer:** independent Fable subagent (build was Opus 5.5), read-only on
the working tree; ran build/vet (host + wasip1)/tests, shellcheck,
golangci-lint v2.14.0 (CI pin, 0 issues) and the CI guards; checked every
doc number against the raw device output.

| 7 | should | No deadline context per call (production always has one), no stderr capture | Fixed — 2 s `context.WithTimeout` per sample, stderr captured into the error |
| 8 | nice | Negative `-n`/`-calls` nil-deref | Fixed — rejected in `main`, `benchReactorWith` guards |

**Fix #7 changed a result:** with the deadline in place the TinyGo reactor
fails under every device's interpreter (a GC pause exceeds 2 s; worst call
932 ms even on an M2 Max interpreter, vs 0.8 ms for plain Go). The harness
now records a failing module as a row instead of aborting, prints max
latency, and all three devices were re-run with the final build; the doc
tables are generated from that run's JSON (committed alongside the doc).

## Verified beyond automated tests

- TDD/mutation: guest handler broken → `TestCommandModuleAnswersEveryEvent`
  and `TestReactorModuleAnswersEveryCall` FAIL; `isAnswer` loosened →
  `TestNonJSONStdoutIsNotAnAnswer` FAIL; restored → pass. Note: the tests
  build guests in a subprocess, so the Go test cache does not see guest
  edits — use `-count=1` after changing a guest.
- `go list ./...` (CI's test pattern) skips the wasip1-only guest packages;
  the deadcode guard's roots don't include `tools/`. No CI impact beyond
  ~5–10 s of guest builds in `go test ./...`.
- Real devices: TECLAST P50T (Android 16), Pi 4, Pi 5 — copies removed
  from each device after the runs.

**Verdict:** safe to merge. Deferred: ut-docs#3912 (persistent compilation
cache, found by this measurement).
