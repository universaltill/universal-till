# Review — Go guest SDK for WASM plugins (ut-docs#3951)

- **Date:** 2026-10-08
- **Branch:** `feat/3951-go-guest-sdk` (+ ut-docs `docs/3951-go-guest-sdk`)
- **Built by:** Claude Opus 5.5. The local lane wrote the SDK, guard and bench; three Opus subagents rewrote the 22 test guests.
- **Reviewed by:** Claude Fable 5.1 (independent subagent, read-only on the tree)
- **Card size:** medium

## What shipped

- **`sdk/plugin`**, a nested module (`go 1.24`, stdlib only) per ADR-0121 F4:
  - `raw_wasip1.go`: one `//go:wasmimport ut` per host function (34, including #1764's `device_*`). Slice-level shims, with `runtime.KeepAlive` after every call. This is the only unsafe code.
  - `hostfns.go`: typed wrappers.
    - Buffer-ABI calls retry once with the reported size and the same request bytes.
    - Stream reads are `io.Reader`s and are never retried.
    - `ViewQuery` starts at the host's 256 KiB view cap, so it never spends a second of the 64 per-event calls.
  - `run.go`: `Run`/`Dispatch`.
    - Unknown event → no answer.
    - `"*"` is a catch-all handler.
    - `ExitCode`.
    - `Event.Timestamp` is a string; `Time()` parses it.
  - `fakehost.go`: `FakeHost` for native `go test`. It uses the same `raw*` shims, so the shared wrappers run unchanged.
- **The parent `go.mod`** has `require … v0.0.0` + `replace => ./sdk/plugin`.
- **`sdk_abi_test.go`** pins `plugin.ABI == MaxSupportedWasmABI`.
- **Conformance.** All 22 core test guests (`internal/plugins/testdata`, `internal/pages/testdata`) run on the SDK. Raw `//go:wasmimport` remains only for deliberately malformed calls the SDK can't express, each commented `raw on purpose`.
- **CI.** `scripts/ci/guard-sdk-hostfns.sh` + `_test.sh`:
  - The host's exports must match the SDK bindings, in both directions.
  - An `Export(` without a same-line literal fails.
  - Every name must be in the ut-docs reference. This check runs in the `adr-taxonomy-guard` job, which has the ut-docs checkout.
  - The build job also runs the nested module's tests and its wasip1 vet.
- **wasmbench `go-sdk-command` guest** plus its test (same answer as `go-command`).
- **Docs.**
  - `docs/plugin_guidelines.md`, `README.md` and `sdk/plugin/README.md`.
  - In ut-docs: the reference's copy-paste bindings are replaced by an SDK section, a core-calls table, and an `event_publish` section (it was undocumented). Each section names its wrapper.
  - `architecture/wasm-runtime.md` gains the SDK overhead table.

The first build decoded `timestamp` into `time.Time` and cost +2.5 ms (+21%) per event under the interpreter. That is why `Timestamp` is a string. The iPhone was not re-measured.

## Findings (Fable) and outcome

| # | sev | finding | outcome |
|---|---|---|---|
| 1 | major | Fake TCP: a closed peer read as `io.EOF`; the till returns `-3` | fixed + test |
| 2 | major | Fake `event_publish` accepted any type; the till allows only `<id>.` | fixed: `FakeHost.PluginID` (default `com.example.plugin`) + test |
| 3 | major | Fake `secret_set` accepted undeclared keys | fixed: `FakeHost.SecretSettings`, UTF-8/128 B checks + test |
| 4 | minor | Hooks ran under the host lock, so an SDK call from a hook deadlocked | fixed (`unlocked`) + test |
| 5 | minor | Fake lacked host caps: storage 128 B / 64 KiB, 256 KiB read chunk, view name/args/64 calls, hex upload token, per-call `Deny` on stream calls | fixed + tests |
| 6 | minor | Guard missed a wrapped/non-literal `Export(` and a binding in a second SDK file | fixed + 2 self-test cases |
| 7 | minor | Docs said an answer survives a non-zero exit; the till discards stdout | fixed (run.go doc, reference) |
| 8 | minor | `ExitCode(0)` exited 0, and a bare `ExitCode` added a 2nd stderr line | fixed: exits 1; no stderr echo + test |
| 9 | minor | httpstream guest's "raw on purpose" rationale was stale (`Handle()` exists) | `maxhandles` now uses SDK + `Handle()`; only `badhandle` stays raw |
| 10–15 | nit | stale file name, overhead wording, example returned a string, sub-ms timeout → 0, non-transitive replace, wrappers unnamed per section | all fixed |

Earlier finding by a guest-rewrite agent: `ViewQuery` could spend two of the 64 per-event view calls. Fixed by starting at the 256 KiB cap. Its test was re-verified to fail on the old buffer size: `view_query calls = 2, want 1`.

## Verified beyond the automated tests

- **Mutation 1:** with the SDK's `storage_set` binding dropping the value, 5 host integration tests fail.
- **Mutation 2:** with the buffer retry disabled, `TestHTTPValidationResponseCap` fails. The host suite really exercises the SDK.
- **TinyGo 0.42** builds an SDK plugin (reviewer). Unused imports are eliminated, so a plugin never imports a host function it doesn't call.
- **Gate:**
  - `go build`, `go vet`, `gofmt` are clean.
  - Full `go test ./...` passes (84 packages); after the review fixes, `internal/plugins`, `internal/pages`, `sdk/plugin` and `tools/wasmbench` pass again.
  - 88/91 build-job guards pass locally. The 3 failures are macOS-only: BSD `sed` in two tests, and shellcheck 0.11 vs the pinned 0.9.
  - `golangci-lint` was not run locally: the installed binary is Go 1.26 and the target is 1.27. CI runs it.
- **No UI surface.** No e2e run, no help topic, no locale keys.

## Verdict

Safe to merge, **after the ut-docs PR**: the reference half of the guard needs the `event_publish` entry. Then tag `sdk/plugin/v1.0.0`.

## Added at rebase: `device_*` (universal-till#1764)

#1764 merged while this PR was in review, adding `device_id_get`, `device_local_ips_get` and `device_timezone_get` (ADR-0140). The guard turned that into a failure on this branch, as designed. The SDK now has:
- `DeviceID`, `DeviceLocalIPs` and `DeviceTimezone`, plus the raw shims;
- FakeHost fields `DeviceID`/`DeviceIPs`/`DeviceTimezone` (all empty → `ErrDenied`), with a test;
- `hostfn_guest`'s `device_info` mode: SDK by default, raw only for the 4-byte buffer probe.

The first buffer is 64 KiB, so a call never retries and never writes a second `device_info_read` audit row. All 12 `Device*` host tests pass, and the guard reports 34 functions, all bound and documented. Small, mechanical, and tested against the host's own tests, so no second review.
