# Review — iOS launch smoke polls for a drawn WebView (ut-docs#5201)

**Date:** 2026-10-30 · **Branch:** `ci/5201-ios-smoke-poll-drawn` · **Lane:** `lane:cloud-41`
**Author model:** Opus · **Reviewer:** independent Sonnet subagent (different model), one round.

## What shipped

- `scripts/ci/ios-sim-wait-drawn.sh` (new, sourced): `wait_for_drawn <shoot> <check> <png> <deadline> [interval]`
  screenshots and checks until the blank check passes or the deadline runs out (one last attempt at the
  deadline). A failed screenshot is a failed attempt with its error kept. Only the final attempt's output is
  printed, so earlier expected "looks blank" lines never become annotations and the failure message is still
  `ios-screenshot-check.swift`'s own. Its log lives in `mktemp`, not in the uploaded screenshot folder.
- `scripts/ci/ios-sim-smoke.sh`: the fixed `sleep 8` + one screenshot is replaced by
  `wait_for_drawn shoot_sim check_png … 60 3`. The resumed screenshot (not checked) is unchanged.
- `scripts/ci/ios-sim-wait-drawn_test.sh` (new): generated blank and drawn PNG fixtures; cases for a late draw
  (passes on the 3rd screenshot), never draws (fails inside a 3 s deadline, polled 2–5 times, error printed
  once), drawn at once (1 screenshot), a failing screenshot (fails with simctl's error), no log left behind.
  Polling cases use a Python stand-in of the Swift rule (< 16 colours or < 2 % non-background on an 8 px grid)
  so the deadlines hold on any runner; on macOS the real Swift check must fail the blank and pass the drawn
  fixture (`UT_REQUIRE_IOS_SWIFT=1` in ios-ci makes a missing swift a failure, like the app-icon test).
- Wired in `ci.yml` (Linux, stand-in) and `ios-ci.yml` `simulator` (macOS, real check, before the smoke).

## Findings

| # | Severity | Finding | Outcome |
|---|---|---|---|
| F1 | major | Swift is interpreted per call (seconds each); with it inside the 3 s "never draws" case the first attempt can already pass the deadline → 1 screenshot → flaky self-test on macOS. | Fixed: polling cases always use the stand-in; the real Swift check runs separately, one shot per fixture. |
| F2 | minor | Under `set -e` a failing `simctl io screenshot` (stderr discarded) exited the smoke silently. | Fixed: a failed screenshot is a failed attempt; at the deadline its error and `::error::taking the screenshot … failed` are printed. Test case added. |
| F3 | minor | `<png>.check.log` sat in the uploaded artifact folder and leaked on an abort. | Fixed: log in `mktemp`, removed on every return; test asserts the TMPDIR ends empty. |
| F4 | nit | `LAST_OUT` unset if the never-draws case failed early → misleading `unbound variable`. | Fixed: initialised. |
| F5 | nit | Stand-in compares RGB, Swift RGBA; parser handles only the generated 8-bit RGB fixtures. | Accepted: fixtures are opaque RGB generated by the test itself. |
