# Code review — Shifts page: cashier name, close form above the fold, no 360px page scroll (ut-docs#5782)

Date: 2026-11-07 · Lane: `lane:cloud-54` · Complexity: easy
Built by: Sonnet (Dev). Reviewed by: Opus 5.5 (independent review + UX §7 gate), fixes re-checked by the orchestrator (Opus).

## What shipped

- **Cashier name.** `CurrentOpenShift` (`internal/data/pos_repo.go`) now
  `LEFT JOIN`s `users` and returns `ShiftSummary.CashierName` =
  `COALESCE(NULLIF(display_name,''), NULLIF(username,''), cashier_id)` —
  the same chain as the no-sale breakdown and reports. A deleted user (no
  row) shows the raw id; an empty id shows "—". No new strings.
- **Layout (`/shifts` only).** Root is `catalog-layout shifts-layout`; the
  shared `.catalog-layout` rule is unchanged (/catalog verified identical).
  From 900px wide: Current Shift card | close/open form side by side, the
  History card spans both columns below. The close form's fields sit in a
  two-column `.shifts-close-grid` (46px controls unchanged), and a
  `max-height: 700px` block tightens this page's card padding/gaps only.
  Below 900px: one column, Current → form → History.
- **360px.** History sits in a labelled `role=region` scroller, and
  `table-cards.js` now re-scans on the `ut:region-refreshed` event that
  `UT.refreshRegion` dispatches — so after an open/close swap the History
  becomes the phone card list again (it stayed a wide table until reload,
  on `main` too).
- `#denom-grid` columns are `minmax(0, 1fr)` with full-width inputs (it
  pushed the page sideways in the new narrower column).
- `#shift-result` scrolls into view on `htmx:responseError` /
  `htmx:sendError`, so a manager-PIN 403 is never hidden under the status bar.
