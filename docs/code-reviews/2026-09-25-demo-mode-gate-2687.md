# Review — till demo mode, slice (a): start gate, broker token, route allow-list (ut-docs#2687)

Design: ADR-0113 §1 items 1–5 and the exact-bind part of item 8. Parts 2
(outbound network, #2795) and 3 (demo session, banner, seed, simulated card
tender, GOMEMLIMIT, #2796) are separate cards. Nothing changes when demo mode
is off; nothing deploys demo mode until the broker (#2688) ships.

## What shipped
- `config.Demo` / `DemoToken` (`UT_DEMO`, `UT_DEMO_TOKEN`) and `AuthDisabled`
  (`UT_AUTH`) read once in `config.Init`; `scripts/ci/guard-demo-env.sh` (+ test)
  fails on any other `UT_DEMO` read, including `os.Environ` prefix scans.
- Migration `046_demo_instance.sql` (single-row flag table, never synced) + repo.
- Start gate (`internal/app/demo_gate.go`): demo needs `UT_DEMO`, a token, a
  regular-file `demo` marker in the data dir, the DB flag, and auth on; a
  flagged DB without demo refuses too. A demo boot failure never enters
  recovery mode. Packaging test: no production packaging mentions `UT_DEMO`.
- `internal/pages/demo_mode.go`, installed only in demo mode inside
  `recoverMiddleware`: constant-time `X-UT-Demo-Token`, `mux.Handler`
  pattern allow-list/deny-list (408 routes: 236 allowed, 172 denied; the `"/"`
  catch-all only for exactly `/`), 64 KiB body cap, multipart with a file part
  refused, localised `demo.not_available` refusal (JSON / htmx fragment / text).
  AST classification test fails on unclassified, doubly-classified or stale entries.
- Exact bind and no browser launch in demo mode (`internal/server`).
- README: "Public demo mode (not for shops)".

`filename*`, chunked bodies, body restore.

## Verified beyond automated tests
Driven run of the built binary: demo without marker and flagged DB without demo
both refuse to start; demo + `UT_AUTH=off` refuses; second instance can't bind;
no/wrong token → 403; `/healthz` with token 200; exit-to-OS, restart, restore,
shop-type, `/nope`, `/faq` → 403 with the localised message; multipart upload
→ 403; 100 KB body → 413; htmx refusal returns the message fragment.

## Deferred

  `cfg.AuthDisabled`); consolidating is a refactor, not a demo risk.
- `/login` without a seeded operator redirects to setup (denied) — the seeded
  demo owner session is #2796.
