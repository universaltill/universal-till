# 2026-09-27 — Instant tap feedback + basket in the first paint (ut-docs#3000)

## What shipped
- **Press feedback** (`base.html` shell script, `app.css`, colour only):
  - A capture-phase `pointerdown` marks a navigation target `.ut-pressed` in the same frame. Targets are `.nav-toggle` and boosted same-origin `a[href]`; tiles, dialogs, `#`, `target` and `download` links are excluded.
  - The mark clears on release, cancel, a move of more than 10px, or a 1 s backstop.
  - A boosted navigation marks the tapped link `.ut-nav-pending` until the new page replaces the rail. The mark is cleared on failure, on an abort, or on a non-page answer.
  - Both states apply under Light effects and reduced motion.
- **Basket inline in `GET /`.** It uses the same render path as `/ui/basket` (`basketViewFor` + `renderCurrentBasket`), with byte-identical markup. It falls back to the lazy placeholder when there is no Engine or the render fails.
- **Slimmer tiles.**
  - The per-tile `hx-on::after-request` modifier opener (118–230 copies) is now one delegated `htmx:afterSwap` listener, keyed on the issuer (`requestConfig.elt`).
  - The redundant `hx-trigger="click"` attributes are removed.
  - Grid size on the seed: 201 KB → 178 KB. The follow-up `/ui/basket` request is gone.

**Design deviation (Dev, accepted):** there is no global loading bar (`.busy-bar` is the reports chart) and the rail has no current-item marker. `.ut-nav-pending` on the tapped link stands in for both. The card was updated.
