# Review: shellcheck 0.11.0 on ubuntu-latest — baseline bump + SC2329 (ut-docs#5206)

Date: 2026-10-30 · Branch: `ci/5206-shellcheck-0-11` · Written by Opus 5.5,
reviewed by Sonnet 5.5 (fresh context, read-only).

## What happened

`ci` / `build` went red on `main` at e850084 and on every open PR. The
ubuntu-latest image now ships shellcheck 0.11.0, so the version guard
(ut-docs#1955) failed with `installed shellcheck is 0.11.0, expected 0.9.0`.
That is exactly the drift the guard exists to surface. Under 0.11.0,
`shellcheck scripts/ci/*.sh` reported 14 new **SC2329** infos ("function
never invoked"). Each one was on a `cleanup()` function that runs only through
`trap cleanup EXIT`. All 14 lines already carried a targeted
`disable=SC2317` for that same false positive, because 0.11 split the
function case out of SC2317 into SC2329.

## What shipped

- `BASELINE_VERSION` (guard) and `BASELINE` (its `_test.sh`) are now
  `0.11.0`. The guard's comments say to bump it deliberately once 0.11's
  findings have been reviewed, and they have been.
- The 14 existing directives are now `# shellcheck disable=SC2317,SC2329`,
  with the reason line above updated. Nothing broader is suppressed.

## Findings (all low, accepted)

1. The drift fixtures are hard-coded (`0.11.3` newer, `0.8.0` older). They
   still sit on both sides of the new baseline. Deriving them from
   `BASELINE` would be tidier, but it is not needed for correctness.
2. Five other tests keep a plain `disable=SC2317` on a trap-run cleanup.
   0.11 reports nothing there, so leaving them alone keeps this diff minimal.

## Verified

- Shellcheck 0.11.0 on `scripts/ci/*.sh` reports 0 issues.
- `guard-shellcheck-version.sh` passes. Its test passes all 5 cases:
  baseline, newer, older, missing binary, unparseable output.
- `guard-ci-tests-sandboxed.sh` passes.
- The reviewer ran 3 of the edited suites (kiosk-engine, netaccess,
  webkit-version), and all pass.
- The reviewer checked each of the 14 by hand: the function is `cleanup()`
  and a `trap cleanup EXIT` follows it.
- No other place pins 0.9.0 outside historical review records.

## Verdict

Safe to merge. It turns `main` green again.
