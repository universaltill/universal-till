# Code review — icon listboxes: rows, sections, type-ahead (ut-docs#5663)

**Date:** 2026-11-06 · **Branch:** feat/5663-icon-grid-2d-nav · **Reviewer:** independent subagent (Opus 5.5; code by Sonnet)
**Precedent:** 2026-11-06-icon-grid-listbox-5601.md (5e4ad7c)

## What shipped
The built-in icon listboxes in the catalog item editor (Item image tab) and the category dialog
(`web/public/radiogroup.js`, `[data-roving-listbox]` branch only) now handle more keys:
- Up/Down move by visual row. They keep the nearest column, cross sections and wrap. Rows come from rendered
  geometry, with a ±1 fallback when there is no layout.
- PageUp/PageDown jump to the first option of the previous or next section. PageUp first goes to the start of the
  current section. Neither wraps.
- APG type-ahead with a 750 ms idle window. A repeated letter cycles. Matching folds case and accents. Space is a
  search character only while the buffer is live.
All of these move focus only: they never set `aria-selected` and never POST. Left/Right/Home/End and the colour
radiogroups are unchanged. Help: one keyboard sentence each in `web/help/en/catalog.md` and `categories.md`.
`web/help/img/manifest.json` is refreshed (surface hash plus the en topic hashes); no PNG changed
(`Docs-Shots-Unchanged: true`). Tests: new `e2e/tests/icon-grid-2d-nav-5663.spec.ts` (19 tests after review fixes); the 5601 spec
drops its linear Up/Down lines.
