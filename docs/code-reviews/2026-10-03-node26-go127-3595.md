# 2026-10-03 — Node.js 26 + Go 1.27.1 across the ecosystem (ut-docs#3595)

**Card:** universaltill/ut-docs#3595 · **Branch:** `chore/3595-node26-go127` in 17 repos · **Author:** Opus 5.5 · **Reviewer:** Fable (independent, different model)

## What shipped
Mend flags EOL Node runtimes (20, EOL 2026-04-30) and old toolchains. Every repo now pins the newest releases:
- **Node.js → 26** (26.10.0; Current, becomes LTS ~2026-10-20): `setup-node` in universal-till, ut-docs, ut-cloud, ut-website, homelab-k8s, ut-admin-app, ut-my-shop, ut-partner-app; the three web apps' Dockerfiles move to `node:26-alpine3.24@sha256:0b36e8c1…9e80`; `engines` (+ lockfile root) `>=26`; homelab `ut-cms` relay image `node:26.10.0-alpine3.24`; `ut-cloud/tests/.nvmrc` 20.11.0 → 26; dead `ut-plugin-faq/.nvmrc` (20.11.0) deleted.
- **Go → 1.27.1**: `go.mod` (`go 1.27.1`) in universal-till, ut-cloud and 8 Go plugins; CI `go-version: '1.27'`; universal-till `golang:1.27-alpine`, ut-cloud `GO_VERSION=1.27.1`. Workflows using `go-version-file: go.mod` (release, android, ios, nightly) follow automatically.
- **golangci-lint v2.5.0 / v2.12.2 → v2.14.0** and `golangci-lint-action` v7/v8 → v9: Go 1.27 support only landed in golangci-lint v2.13.0, so older ones would not lint the modules at all.
- ut-cloud: dropped the `GOTOOLCHAIN: auto` workaround for helm v3.22.0 (needs go ≥ 1.26, now met).
- universal-till: `packaging/macos/Info.plist` `LSMinimumSystemVersion` 11.0 → **13.0** (Go 1.27 requires macOS 13), with a new CI guard `scripts/ci/guard-macos-min-version.sh` (+ `_test.sh`) so the bundle floor can't drift behind the toolchain again.
- Docs: version lines in universal-till `AGENTS.md`, `tests/e2e/README.md`; ut-cloud `README.md`, `docs/technical-reference.md`, `docs/plugin-developer-guide.md`; ut-docs `onboarding/BOOTSTRAP.md`.
