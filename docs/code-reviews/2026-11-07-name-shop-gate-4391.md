# Review: name-shop gate on an unnamed main till (ut-docs#4391)

Branch `feat/4391-name-shop-gate`. Built by Sonnet; independent review by Opus 5.5 in its own worktree.

## What shipped
- `internal/pages/name_shop.go`: `nameShopGate` sits inside `auth.Middleware` (auth-on branch only). A signed-in user with the `settings` permission, on a **main** till whose shop name is a placeholder or whose `till.name` is empty, gets a 303 to `/name-shop?next=…` on a full admin page GET. A boosted nav-rail click gets `HX-Redirect` instead.
- **Never gated:** `/` (sale), `/tables`, `/open-orders`, `/orders`, `/journal/`, `/refund/`, `/self-order*`, `/kitchen-display/`, `/o/`, `/plugin/`, help, login/lock/logout/setup, APIs, fragments, assets, the cloud-move approval, cashiers, replicas, and `UT_AUTH=off`.
- `GET`/`POST /name-shop` asks only for the missing names. The POST saves through `applyStoreName` / `applyOwnTillName`, extracted verbatim from the Settings handlers (same write-through, audits, register rename). `next` is same-origin only and falls back to `/settings`.
- `POST /api/auth/setup` takes an optional, validated `till_name`; the e2e worker till sends it.
- English i18n keys + meta; `name_shop` area. Help: `display.md` claims `/name-shop`, items 6 and 9 reworded.
- The dismissible "Name your shop" banner is hidden on `/name-shop`.
