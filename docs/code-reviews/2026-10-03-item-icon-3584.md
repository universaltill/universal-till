## What shipped
Items get the category icon machinery of #2506/#2653/#2717: `items.icon` (migration **066**), `CatalogRepo.SetItemPicture` (thumbnail path XOR icon id, last writer wins, one tx), `SaveItem` takes `Icon` (format check, `saveItemIconTx` applies the one-picture rule: an icon replaces a photo — file removed — or a library tile; `""` clears the icon and a library tile but keeps a photo), `SetItemThumbnail`/`ClearItemThumbnail` route through it so the till's own upload, library pick and "No image" clear the icon, the importer's placeholder skips an icon-only item, the snapshot reports `iconid.EffectiveIcon`, and `ui.ItemThumb` draws the icon on the sale screen, quick buttons, sell-screen search, self-order kiosk and the catalog list when there is no image. Read-only on the till side: no new copy, no locale keys.

## Checked, no issue (reviewer)
- **Money:** nothing touches `base_price`, `price_history` or any money path; the `Price` fields only appear in untouched struct literals that gained an `ImageURL` line.
- **Image XOR icon in every write path:** till upload (`handlers.go` upload → `SetItemThumbnail`) and library pick (`SetItemThumbnail`) → `SetItemPicture(path, "")` clears the icon; till "No image" → `ClearItemThumbnail` → both cleared; `save_item` from my. → `saveItemIconTx` (photo: row deleted and the file removed by `RemoveItemUpload`, guarded by `safeCategoryID` plus an exact `ItemThumbURL` match so a DB value is never used as a path; library tile: row deleted; `""`: photo kept, library tile dropped); `set_catalog_image` apply → `StoreItemPhoto` → `SetItemThumbnail`; clear → `ClearItemPicture`, and an icon-only item counts as "has a picture" so clear is not a no-op replay (`current += icon`). `EnsureDefaultThumbnail` skips an item that shows an icon.
