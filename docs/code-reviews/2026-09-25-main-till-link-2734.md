# Review — main-till link, main side: `GET /api/sync/link` WebSocket, `internal/fleetlink` (ut-docs#2734)

- **Author:** Opus 5.5 (Dev subagent). **Reviewer:** Fable 5.1, fresh context, worktree `feat/2734-main-till-link`, one round. Card complexity:hard.
- **Binding design:** ADR-0114 §1, §2, §4, §8, §11 (task 1 of its breakdown). §3's replica behaviour is #2735, §7 TLS is #2736.

## What shipped
1. **`internal/fleetlink`** (new, `github.com/coder/websocket`): transport-neutral envelope `{v,id,type,reply_to,payload}` (`envelope.go`, `messages.go`), a `Conn` interface with the one WebSocket adapter (`ws.go`), `Hub` (one `Peer` per till id, `MaxConns` 32, latest `report` per till, request handlers) and `Peer` (reader = the HTTP handler goroutine, exactly one writer, bounded handler goroutines).
2. **§8 bounds, all binding values in `Config`/`DefaultConfig`:** 256 KiB read limit (also the cap on what we send), 64-message / 1 MiB outbound queue that fails `busy` at once, 8 requests in flight each way, `sync` nudges coalesced into a per-peer `atomic.Uint32` (never queued), a peer that can't take a write for 10 s is dropped, 5 s app-level ping, gone after 12 s, `bye` on shutdown; hello and report strings clipped to 64 bytes before they are kept; report store bounded at 256 with oldest-first eviction.
3. **`GET /api/sync/link`** (`internal/pages/sync_link.go`): auth-middleware exempt, `syncTill` bearer check before the upgrade, 409 on a replica, 503 + `Retry-After` at the cap; hello carries the main till's id, version, platform, sync-protocol level and the same admin/plugins/stock fingerprints the HTTP pulls serve; a link frame refreshes `tills.last_seen_at` at most every 30 s (`TillsRepo.TouchLastSeen`) so table-claim TTLs treat a linked till as alive.
4. **Nudges:** `Deps.NudgeLink` (nil-safe, non-blocking) at every change point — `RequestSyncPush` (sale/refund/stock adjustment → stock, orders), journal ingest when `applied > 0`, `ReloadPlugins` → plugins, the three held-sale choke points and the `/api/sync/held-sales/*` endpoints → held_sales + tables, table claim/release write-throughs, `/api/sync/tables/*` and the manager's force-release → tables, `applyOrderStatusCore` → orders. `admin` (catalogue, settings, users, roles, PINs — #2731) comes from a 1 s watch of the migration-023 `sync_admin_version` counter while ≥ 1 till is linked, so every writer is covered without a hook per call site.
5. **Revoke closes the link at once** (4003) and the bearer is gone, so it cannot reopen. **Shutdown:** a wg-joined goroutine on `bgCtx` calls `Hub.Close` (bye → `CloseNow` → wait for every link goroutine); needed because `http.Server.Shutdown` does not track hijacked connections.
6. **§11 advertisement:** `"link":1` in `GET /api/sync/ping` and `link=1` in the mDNS TXT record; `discovery.Candidate.Link` reads it (0 for an older main till, junk → 0).

## Verified beyond the automated tests
- **Goroutines / leaks:** reader = handler goroutine, one writer, handlers ≤ 8 and joined by `hwg` before `run` returns; `Request` exits on reply, deadline or `stop`; `pending` entries always deleted; the only writer both writes and closes the `Conn`, so a stuck peer is unblocked by the writer's 10 s timeout, never by a second closer. The 1 s admin watch is one goroutine for the process lifetime doing a mutex read per tick with no links — not a leak.
- **Locks:** `Hub.mu`, `qmu`, `pmu`, `hmu` are all leaf locks; `Nudge`, `Close` and `Disconnect` snapshot under the lock and touch peers outside it. No lock is held across `conn` I/O.
- **Memory:** peers ≤ 32 (checked pre-upgrade in `admit` and again under the lock in `ServeConn`), reports ≤ 256, per-peer queue/in-flight/pending ≤ config, hello and report strings clipped, `dirty` is 32 bits per peer, inbound frames ≤ 256 KiB. Nothing grows with a slow or hostile peer.
- **Auth/origin:** bearer checked before `Accept`; middleware exempt list carries the path (test pinned). coder/websocket's default same-host `Origin` check stays on (no `OriginPatterns`); it is not what protects the route — a LAN page cannot set `Authorization` on a WebSocket, so the bearer alone defeats a browser hijack — and Go dialers send no `Origin`.
- **Production middleware chain** (the pages test mounts a bare mux): `recoverMiddleware`'s `recoveryResponseWriter` implements `Hijack` and delegates; `auth.Middleware` passes exempt paths through unwrapped; `BoostedNavigation` wraps only HX-Boosted requests. The upgrade reaches `http.Hijacker` in production.
- **No admin-nudge loop from `TouchLastSeen`:** migration 023's `tills` UPDATE trigger has `WHEN NOT (OLD.name IS NEW.name AND OLD.enrolled_at IS NEW.enrolled_at)`, so `last_seen_at` writes never bump the generation.
- **Shutdown order in `app.Run`:** `stopBg()` → `Hub.Close` (bye, `CloseNow`, wait) runs inside `drainBackgroundServices` before `database.Close`; hijacked connections cannot outlive the server.
- **DoS:** cap checked before the upgrade (503) and under the lock after; replace-own-link at the cap needs a valid bearer and is bounded by the 5 s handshake per old link; a hijacked connection that never sends a frame is dropped at 12 s; an oversized frame closes with 1009 (test); the server sets no `ReadHeaderTimeout` for any route — pre-existing, not this card.
- **TDD claims re-verified by the reviewer:** removing the `applied > 0` nudge in `sync_sales.go` makes `TestSyncLink_JournalIngestNudgesStockAndOrders` fail (no sync frame); removing `d.Link.Disconnect(id)` in the revoke handler makes `TestSyncLink_RevokeClosesTheLink` fail with `4008 … want 4003`. Both restored and green.
- **Android:** `GOOS=android GOARCH=arm64 CGO_ENABLED=0 go build ./internal/fleetlink/ ./internal/pages/common/` passes; `coder/websocket` is pure Go.
