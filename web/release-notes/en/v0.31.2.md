## New

- **See what's new before you update:** when an update is waiting, Settings → Software update now shows a manager or admin the release notes of the new version above the install button — for every version the update includes, newest first, in the till's language where translated. If the notes can't be loaded, the till says "Release notes unavailable" and you can still install the update as usual.

## Improved

- **Plugin forms keep what you typed:** if a plugin can't complete an action — for example it takes too long to answer — its page stays as it was with a short notice on top, and everything you entered is still there, so you can simply try again.
- **Pictures in plugin suggestions:** after **Identify by camera**, a plugin can now show its own small picture next to each item it suggests. If it has none, you see the item's own photo as before.

## Fixed

- **Settings messages appear in the right place:** when Settings refuses a change — such as the languages shown to staff or the till name — you now see only the reason next to that setting, no longer a general "something went wrong" banner at the top of the page as well.
- **Clearer note while your tax plugin is pending:** if the plugin catalog is online but doesn't offer the tax plugin for your country yet, Settings and the setup wizard now say so and that the till keeps checking, instead of claiming it is still installing because you are offline.
- **Setup no longer misreads an offline till:** when the till has been offline for a while, the setup wizard now shows that the plugin catalog can't be reached, rather than saying the tax plugin isn't in the catalog based on an old check.
- **Drawer openings on every till count:** when the cash drawer is opened without a sale on a joined till, that opening now reaches the main till, so your cloud reports count drawer openings from all tills, not only the main one.
- **Plugin panels' forms work:** a form or photo upload in a plugin's panel on Reports, End of day, Settings, Administration or the item edit window now goes through even when the plugin has only been allowed to show panels there.
