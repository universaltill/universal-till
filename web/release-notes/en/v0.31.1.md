## New

- **Update another till from the main till:** on the main till's Tills page, a manager can press **Update now** for any joined till that is behind it. The joined till installs exactly the version the main till runs; if it fails, the same button tries again.
- **Plugins can take files:** a plugin page can now ask you to upload a file, such as a price list, within a size limit the plugin declares.
- **Plugins can run on a schedule:** a plugin you have given the schedule permission can now run small tasks on its own every few minutes. It never runs in the middle of a sale and stops as soon as you disable or remove the plugin.

## Improved

- **Backups include your photos:** every backup now also holds the photos you uploaded for items and categories and your receipt logo. Restoring a backup — even on a new device — brings them back, and the one file you download is the whole backup.

## Fixed

- **Older till registrations stay connected:** a till still on an older shared registration now moves onto its own sign-in when the shop has no subscription, instead of being cut off from the cloud.
