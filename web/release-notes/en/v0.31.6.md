## Improved

- **Slow self-hosted AI no longer gives up after 30 seconds:** when a plugin runs a longer task in the background, such as identifying a product from a photo with an AI model on your own mini-PC or Raspberry Pi, the till now waits for the model's answer until that task's own time limit (up to five minutes) instead of stopping after 30 seconds. Selling is never held up by it.
- **Product identify plugins can be told your pick:** when you tap one of a plugin's photo matches, the till now also tells that plugin which item you chose, if the plugin has asked to hear about it, so it can improve its own matches.
- **Generating missing SKUs is much faster on large catalogs:** **Generate missing SKUs** on the Catalog page now works out all the new SKUs in one go, so thousands of items take a fraction of a second instead of several seconds. Its preview no longer holds up a sale, or waits for one.
- **See unencrypted plugin connections before you install:** on a plugin's store card, a permission to download data from an internet address over plain, unencrypted HTTP now has its own line saying so, and that the plugin is expected to check the data's signatures itself. Before, it looked the same as an encrypted connection.
- **Price-only plugins ask for less:** a plugin that only shows prices, such as a menu board or shelf labels, can now read your shop's name, currency and default language without asking for access to your sales and receipts.

## Fixed

- **Move table on open orders stays put:** on the **Open orders** list, the **Move table** button no longer jumps when it opens, so tapping the same spot again closes it.
- **Clearer language-pack message:** Settings → Data no longer says a free language pack is "installing" when none may exist yet. It now says the till is looking for one and installs it in the background if the plugin catalog has it.
- **Additional tills explain their updates:** on an additional till, Settings → Software update no longer shows an "Update automatically" box that read Off while the till actually followed the main till. It now says the till follows the main till's version and that automatic updates are changed on the main till, or, when they are off on the main till, that this till won't update by itself.
- **Keyboard stays inside open dialogs:** in a few older till dialogs (such as hold, open orders, deposit and manager approval), pressing Tab could move to a product or the Pay button behind the dialog. Tab now stays inside the dialog.
- **Fixed problems stop showing in the online shop manager:** when an additional till could not sync a plugin or found its pairing removed on the main till, the online shop manager (my.universaltill.com) could keep showing "Attention needed" for that till for up to a day after the problem was fixed. The warning now clears at the till's next check-in after it recovers.
- **Additional tills reconnect to the main till by themselves:** if the main till briefly refused an additional till's live connection, for example while it was being restored, the additional till carried on with its slower regular sync and did not reconnect until it was restarted. It now reconnects at its next regular sync once the main till accepts it again.
- **Clear messages when registering, claiming or pairing a till:** in Settings → Till registration, **Claim this store** and **Pair with a shop** no longer show raw technical error text from the cloud when something goes wrong. They now say what happened in your language, for example that the till has no cloud address set up, that another attempt is still running, or, on an additional till, that the cloud is not available for this shop.
