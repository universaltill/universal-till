## New

- **Finding the main till over the internet, not just the network:** if an additional till loses contact with the main till on the shop's own network (for example, a Wi-Fi setting that blocks devices from seeing each other), it now also asks the cloud for the main till's last known address before giving up and selling offline.

## Improved

- **Faster pairing, till removal and backups:** approving or declining a till pairing request, removing a till and running "Backup now" now update instantly in place, instead of reloading the whole screen.
- **Cloud sync pauses for unpaid shops:** a shop that isn't on a paid plan no longer has its till quietly contacting the cloud in the background. A "Check for a paid plan" button appears where needed to pick it back up as soon as the shop is paid and claimed.

## Fixed

- **Catalogue edits no longer silently overwrite each other:** editing an item's variants, modifier groups, categories or quick buttons from an additional till could overwrite a change someone else just made on the main till without any warning. It's now caught and refused, the same protection the item editor already had.
- **Cancelling an order twice:** if an additional till couldn't reach the main till, cancelling an order there could let it be cancelled again later. The till now shows a clear message and refuses to cancel locally in that situation.
- **Tax rate entry was inconsistent between screens:** the shop's default tax rate and a tax code's rate could accept slightly different values, including occasionally a rate over 100%. Both now behave the same way and correctly refuse anything above 100%.
- **A kiosk order typed in by hand could be lost:** if the till restarted itself for an update while a hand-entered counter order was still open, that order could vanish without a trace. It's now treated the same as any other open order and is never silently dropped.
- **Device status reports reaching the cloud again:** tills were failing to send their regular diagnostic check-in, so device health could look out of date in the cloud.
