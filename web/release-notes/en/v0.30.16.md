## New

- **Shopify import:** you can now import your products from a Shopify products CSV export, including variants and barcodes.
- **Easier pairing of a new till:** the main till now shows a short 6-character code and its address in large text. Type both on the new till to pair it; the QR code and the full code still work.
- **Kiosk mode from a PIN:** signing in with the kiosk user's PIN now switches the till straight into self-order mode. Signing in as anyone else through the kiosk's lock link switches it back to the sale screen.
- **Back button:** every page except the sale screen now has a ← Back button. It takes you back to the page you came from, or one level up when there is nothing to go back to. It works in the iPhone app too, which had no way back.
- **UK VAT invoices:** when your VAT number is set, receipts print your address, VAT number and the total for each VAT rate, and full invoices carry the details a UK VAT invoice asks for.
- **Pair with a shop:** Settings → Till registration has a new **Pair with a shop** box. Enter a pairing code from your shop's cloud account to add this till to that shop, or to reconnect a till that was removed.
- **Custom roles on the till:** roles you create in your cloud account now show on the Permissions page, and you can give them to staff on the Users page.
- **Camera barcode scanning on iPhone and iPad:** the sale screen's camera button now reads barcodes on iPhone and iPad too. The pictures never leave the device.
- **Archived reports in the cloud:** when **Keep reports on** is set to Cloud only or Till + cloud, the main till now uploads its archived reports to your cloud account. If the upload is refused because the subscription is not active, the status bar and the Report retention card say so, and the reports stay on the till.
- **Option sets:** on the till you can now rename an option set, edit, reorder and remove its values, switch it off, or delete it. Deleting is refused while an item still uses it, and the page lists those items.
- **More from your cloud account:** you can now change the remaining till settings, item variants, option sets and an item's net quantity from your cloud account, and see which printers and other devices are connected to each till.
- **Unit price on pre-packed labels (UK):** a new setting prints the unit price (per kg, per litre or per item) on the shelf label of a pre-packed item. It is off by default and uses the net quantity you set on each item.

## Improved

- **Shelf labels in the UK:** a label for an item sold by weight now prints its price per kg.
- **Phone menu:** on a phone, administrators now find Users, Promotions and Translations in the ☰ menu on every screen.
- **Shopify import:** a Shopify export re-saved as an Excel (.xlsx) file is no longer imported wrongly. You are asked to upload the original CSV file instead.
- **Settings save in place:** saving the printer, till name, register, invoice, telemetry, shop name, report retention or basket-panel card no longer reloads the whole page.
- **Catalog import:** the preview now shows the SKU the till will give each item that has none. You can change it before you import.
- **Catalog files:** the catalog CSV export and import, and Excel (.xlsx) imports, now keep each item's net quantity and its age-restricted flag.
- **Updates on Linux:** when a Linux till cannot install an update by itself (for example, its install folder can't be written), the status bar and Settings → Software update now say so and link to the steps in Help. Before, it skipped the update without a word.
- **Cloud sign-in refused:** if the cloud refuses this till's sign-in three times in a row, a status chip explains why and what to do. The till keeps selling offline and tries again every hour.
- **Tables on a phone:** tables now show as stacked cards, so nothing scrolls sideways. Rows with many details have a More / Less button.
- **Report an issue on a phone:** the panel now opens as a full-screen sheet with bigger buttons. The menu and Back stay reachable.
- **Safety copies before a restore:** the copy of your data the till keeps before restoring a backup is now kept for your shop's legal retention period, not deleted after 30 days.

## Fixed

- **iPhone and iPad:** tapping a text field (for example Change PIN) no longer zooms the screen in, and pages can no longer be pinched out of shape.
- **Categories:** who may edit categories now follows the catalog permission, the same as items. Built-in roles keep the access they had.
- **Tax codes at 0%:** an item on a 0% tax code (for example zero-rated food) is now charged 0%. Before, it was charged your shop's default rate. Check your prices if you relied on that. Items with no tax code still use the default rate.
- **iPhone:** pop-ups now open fitted to the screen instead of zoomed in.
- **Germany (TSE):** when the signing service says it cannot sign a sale, the sale is no longer completed without a signature. Payment is refused, and a card payment already taken is reversed.
- **iPhone and iPad:** recording a voice note in Report an issue no longer closes the app. iOS now asks for microphone access the first time. On older iOS versions, which can't record voice notes, the button says so instead.
- **iPhone and iPad:** the Bluetooth devices page no longer says your Bluetooth is missing. It now explains that scanners and keyboards are paired in the Settings app → Bluetooth, and that Bluetooth printers and scales can't be used from an iPhone or iPad.
- **0% default tax rate:** in a shop whose default tax rate is 0%, items with no tax code were charged 20%. They are now charged 0%.
- **Completed sales:** a completed sale can no longer be reopened or marked as refunded behind the scenes, where it dropped out of every report. Voiding it needs the refund permission or a manager PIN.
- **Erasing a customer:** erasing a customer's data now also removes their name and contact details from held (parked) orders and from the shop's other tills.
- **Germany (TSE):** a cash refund or return is now refused when the signing service says it cannot sign it, instead of completing without a signature. Nothing is restocked or recorded.
- **Catalog cleanup and Remove sample data:** these no longer fail when an item was only ever voided, comped or wasted. Those items are now kept as history.
- **Clear transaction history:** voids, comps and waste now move to the archive with the rest, so they no longer stay in the Shrinkage & Loss report.
- **Tax plugin:** the setup wizard no longer offers a tax plugin when one is already installed, and the Settings reminder stops trying to install a second one.
- **My reports on a joined phone or iPad:** it no longer asks you to finish setting up the device. A report waits and sends by itself once the main till has given the device cloud access.
- **iPhone and iPad:** they can now find the main till on the network, and be found as one. If Local Network access is turned off, the Tills page and the setup wizard say so.
- **iPhone and iPad:** Take screenshot in Report an issue now captures the till, not the share prompt.
- **Phone:** after a sale, the Print, New customer and Refund buttons no longer get cut off.
- **Phone:** tapping a topic in the manual now opens it. A "Manual topics" link takes you back to the list.
- **Additional tills:** when the main till restarts or updates, the other tills no longer report it as a lost connection.
- **Linux desktop app:** links to websites now open in your normal web browser.
