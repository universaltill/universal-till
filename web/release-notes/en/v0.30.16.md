## New

- **Shopify import:** you can now import your products from a Shopify products CSV export, including variants and barcodes.
- **Easier pairing of a new till:** the main till now shows a short 6-character code and its address in large text. Type both on the new till to pair it; the QR code and the full code still work.
- **Kiosk mode from a PIN:** signing in with the kiosk user's PIN now switches the till straight into self-order mode. Signing in as anyone else through the kiosk's lock link switches it back to the sale screen.
- **Back button:** every page except the sale screen now has a ← Back button. It takes you back to the page you came from, or one level up when there is nothing to go back to. It works in the iPhone app too, which had no way back.
- **UK VAT invoices:** when your VAT number is set, receipts print your address, VAT number and the total for each VAT rate, and full invoices carry the details a UK VAT invoice asks for.

## Improved

- **Shelf labels in the UK:** a label for an item sold by weight now prints its price per kg.
- **Phone menu:** on a phone, administrators now find Users, Promotions and Translations in the ☰ menu on every screen.
- **Shopify import:** a Shopify export re-saved as an Excel (.xlsx) file is no longer imported wrongly. You are asked to upload the original CSV file instead.

## Fixed

- **iPhone and iPad:** tapping a text field (for example Change PIN) no longer zooms the screen in, and pages can no longer be pinched out of shape.
- **Categories:** who may edit categories now follows the catalog permission, the same as items. Built-in roles keep the access they had.
- **Tax codes at 0%:** an item on a 0% tax code (for example zero-rated food) is now charged 0%. Before, it was charged your shop's default rate. Check your prices if you relied on that. Items with no tax code still use the default rate.
- **iPhone:** pop-ups now open fitted to the screen instead of zoomed in.
- **Germany (TSE):** when the signing service says it cannot sign a sale, the sale is no longer completed without a signature. Payment is refused, and a card payment already taken is reversed.
- **iPhone and iPad:** recording a voice note in Report an issue no longer closes the app. iOS now asks for microphone access the first time. On older iOS versions, which can't record voice notes, the button says so instead.
- **iPhone and iPad:** the Bluetooth devices page no longer says your Bluetooth is missing. It now explains that scanners and keyboards are paired in the Settings app → Bluetooth, and that Bluetooth printers and scales can't be used from an iPhone or iPad.
