## New

- **Stock levels in the online shop manager:** my.universaltill.com now has an **Inventory** page under **Manage shop**. It shows every active stock-tracked item at the stock location you pick, and a manager can correct a quantity with a reason. Your main till applies the change.

## Improved

- **Gift voucher item in your language:** if your shop's language arrived after setup (for example, setup ran offline), the gift voucher item that setup created is now renamed into that language. An item you renamed yourself is left alone.
- **Plugins can answer imports and exports in your language:** the till now tells import and export plugins which language you use, so plugins that support it reply in that language.
- **Lighter sales-report syncing:** the till now rebuilds the sales reports it sends to the cloud for past days only when something changed on that day, instead of every time.

## Fixed

- **Gift vouchers search:** searching for **MÜLLER** now finds *Müller*. Upper and lower case are ignored for accented letters too. The search and status also stay in the page address, so going Back from a voucher or reloading keeps them. On an empty list, the page no longer offers an export with nothing in it.
- **Search in more languages:** the item search on the sell screen and the customer name search now ignore upper and lower case for accented letters too, so **MÜLLER** finds *Müller*. Every one of these name searches, gift vouchers included, also handles Turkish dotted and dotless i (**ISPARTA** finds *Isparta* and *ısparta*), **STRASSE** finds *Straße*, and text pasted from a Mac matches too.
