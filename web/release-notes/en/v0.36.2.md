## New

- **Optional encrypted off-site backups:** A shop can now keep an encrypted copy of its backups off the till. The key stays with the shop, and the cloud cannot read the copy. A restore brings the data back on a new till. Turning it on needs the owner's approval.
- **The till checks in with the cloud:** A till now checks in with the cloud when it starts, and again when its version or one of its plugins changes, so the cloud always knows which version each till runs. There is a switch in Settings under Privacy to stop it.
- **Photo import by SKU:** The catalogue import can attach item photos by SKU from a CSV or a ZIP file.
- **About screen:** A new About screen shows the version and the licences.
- **Update notice on Android:** The Android app tells you when a new version is available and asks for the install permission it needs.

## Improved

- **Touch scrolling:** The Import and Tax codes dialogs now scroll by touch.
- **Card plugin help:** The help explains how to install, set up and update a card plugin.
- **Plugin store messages:** A failed plugin download or install is now shown in your language instead of a raw message.
- **Shifts page:** The Shifts page shows the cashier name and fits a narrow screen without sideways scrolling.

## Fixed

- **Saving on Android tablets:** Save to Downloads now opens the system save dialog on the tablet.
- **Card refunds after many card sales:** Card refunds keep working after a till has taken more than 1,024 card sales.
- **Unknown card result:** If a card payment ends with an unknown result, the basket stays on that payment and any part already taken is reversed if a later step fails.
- **Sale screen:** A basket refresh asked for by the server no longer clashes with an edit in progress.
