## Added

- **Online orders:** orders taken on a web shop or marketplace now appear on a new Online orders page on the till (view only; status changes are made on my.universaltill.com). Their stock is applied once.
- **Barber and grooming pictures:** 31 new built-in pictures for items and categories (clippers, razors, combs, beard oil, aftershave and more).

## Improved

- **Joining a shop is shorter:** when the shop you join from my. already has a shop type, the setup wizard no longer asks for it again.
- **No second sign-up:** a till that joined a my. shop is no longer asked to register on the last wizard step.
- **Cloud terms:** a registered till can accept the cloud terms later, and the plugin store asks for them before a download.
- **Self-order kiosk:** a basket with an age-restricted item goes to the counter straight away instead of after you pick a payment method.
- **Plugin screens:** plugin text now follows its own writing direction, so right-to-left plugin labels and buttons no longer scramble.

## Fixed

- **Cloud changes apply once:** if a change sent from my. was retried after a network hiccup, the till could apply it twice. Each change is now applied exactly once.
- **Item photos on the sell screen:** a photo you set for an item now shows on its tile instead of an old picture.
- **Connection banner:** the cloud connection banner now reflects the real state of a till that joined from my.
