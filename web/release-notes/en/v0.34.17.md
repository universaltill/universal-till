## Improved

- **Joining a shop is shorter:** when the shop you join from my. already has a shop type, the setup wizard no longer asks for it again.
- **No second sign-up:** a till that joined a my. shop is no longer asked to register on the last wizard step.

## Fixed

- **Cloud changes apply once:** if a change sent from my. was retried after a network hiccup, the till could apply it twice. Each change is now applied exactly once.
