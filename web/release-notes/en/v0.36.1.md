## New

- **Your country's tax-rate plugin installs itself:** When a new till is set up, it now looks for the free tax-rate plugin for the shop's country in the plugin store and installs it, starting with the UK. A plugin that fails its start-up check is never kept, and checkout carries on. A manager can see the status on the setup page and in Settings, and can uninstall it from the Plugins page, after which it is not installed again.
- **Mid-shift X report:** The Shifts page can now show an X report for the open shift without closing it, and print it. The Reports page also has a till-wide "day so far" preview on the end-of-day tab.
- **Gift voucher slips:** A slip can be printed for a gift voucher, including a top-up, from the voucher page. With no receipt printer set up, it prints through the browser. The slip carries the shop's own text and the issue date.
- **Pick icons in your own languages:** The icon search now finds icons by their names in the shop's languages, and the automatic suggestion does the same. An item keeps its icon when a photo is added, and a photo is not lost when its icon is changed from the cloud.
- **Catalogue import:** The import reads a reorder-level column, and an XLSX file's Track inventory column.
- **Clear confirmation questions:** Confirmations on the till now appear in the till's own dialog instead of the browser's pop-up, and their buttons say what they do, for example Keep order or Cancel order.
- **F11 for full screen:** On the desktop till, F11 switches between full screen and a normal window.

## Improved

- **Printing:** A printed receipt or voucher slip no longer carries the browser's address and date in the margins, and an invoice prints only the document. A till with no printer says what to do instead of showing only a Save-as-PDF dialog, and Settings → Printer warns when the till has no system printer. In the Android app, printing opens the system print dialog.
- **Dates and percentages:** Printed dates follow the same order as on the screen, and percentages follow the language's sign placement and digits.
- **Till ID on the Tills page:** The main till's Till ID, the one a scan on the local network shows, is now on the Tills page.
- **Plugins:** A plugin's settings can be shown as tabs. A plugin the store has withdrawn stays off and cannot be enabled, installed or rolled back to.
- **Names:** Till and customer names can no longer hold line breaks, tabs or hidden formatting characters, and the setup page accepts a shop name of up to 80 characters.
- **Joining a till:** When a till is refused for using a plain web address, the message now says what to do.
- **Reports and shifts:** A closed shift shows its cash count again, the Shifts page shows the shift's no-sale drawer opens, and the confirmation after opening a shift or adjusting cash no longer shows a technical code.
- **Easier to use by keyboard and touch:** Focus stays on the control after a form is sent, the on-screen keyboard no longer covers the field you are typing in, and a ticked icon is marked clearly. Rows in the last five admin lists open for editing when tapped.
- **Android:** The screen stays on while the till is in front, and Save to Downloads uses the system save dialog and says why when it fails.

## Fixed

- **Android tablets on Fire OS 7:** The Android app no longer crashes at start-up on 32-bit (armv7) devices running Fire OS 7, such as older Fire tablets.
- **Reconnecting a till:** A registered till that lost its cloud sign-in now proves it holds its own key and reconnects by itself. If that is not possible, a manager sees Reconnect this till or Register as a new shop and confirms it.
- **Numbers after a restore:** After a backup is restored, receipt and Z numbers jump ahead so none is used twice, even if the restore is interrupted and undone.
- **End of day and promoted tills:** A till's own late sales are counted once in the next Z report after it becomes the main till, and rows saved while offline count in the Z of the day they arrive. A cash refund lowers expected cash at shift close, as it does at end of day, and cash tips follow one rule on every report.
- **Deleting an item:** An item that was never sold can be deleted even if it has comps, waste or ID checks recorded.
- **Quantity edits on the sale screen:** Two quick changes to the same basket line can no longer overwrite each other.
- **Till stops if its data is deleted:** A till whose data folder is deleted while it runs now stops, instead of carrying on without saving.
- **Reports on narrow columns:** Z reports and cloud reports line up correctly with wide characters.
- **Help:** The help now explains what to do when a card reader times out and a customer taps late, covers approving, denying and removing a till, and no longer names an out-of-date folder for item photos.
