## New

- **Sell gift vouchers like any item:** give a catalogue item the type **Gift voucher**. Tapping it asks for the value and the card number: scan a pre-printed card, or leave the number empty and the till creates one. The voucher goes into the sale like an item and is issued when you take payment. It's booked as a voucher, not as sales, and gets no discounts. A voucher can be sold on its own. Spending it later takes the amount off its balance. This replaces "Sell a voucher" in the Split tab.
- **A clearer Plugin Store:** the store now shows small tiles with each plugin's logo, type and install state. Tap a tile for its detail page with the full description and what the plugin may access.

## Improved

- **AI assistants on a joined till:** on a till that follows a main till, an AI assistant now says straight away that it can't change the catalogue there, instead of after you've read its suggestion.

## Fixed

- **Item names on phones:** item tiles on a phone use a slightly smaller name, so words like "Dishwashing" no longer break in the middle.
- **Plugin settings on phones:** the takeaway tax overrides no longer make the settings page scroll sideways.
