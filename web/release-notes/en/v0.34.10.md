## Improved

- **Import Preview shows what a row will lose:** before you import, the Preview now marks a row with ⚠ and the reason when it will import without something from the file — a barcode that can't be added, a tax rate that couldn't be read (the item gets the till's default rate), an invalid net quantity, or a backup photo that can't be found. Before, you only saw this in the summary after importing.
- **Joining a till that already has sales:** when a join is refused because this till has sales, the warning and its **Replace this till's sales and data** tick box now appear above the join tabs — also in the first-start wizard, which was a dead end before — and the box is highlighted until you tick it. A sale made while the join is finishing now stops the join instead of being lost.

## Fixed

- **Retrying a failed join:** a join that failed partway no longer leaves this till registered on the main till, so trying again with the same name no longer says the name is already in use.
- **Manual — one-tap payment:** the manual now says the Pay panel's one-tap button uses the first active payment method in your list (Cash on a new till), not always cash.
