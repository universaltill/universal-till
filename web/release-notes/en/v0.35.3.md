## New

- **Gift voucher top-ups on an additional till:** An additional till can now sell a top-up for a gift voucher. It checks the voucher with the main till first, and the main till adds the balance when the sale arrives. If the main till can't be reached or needs an update, the top-up is not added and the page says so; the rest of the sale is not held up. The voucher list and its search also ask the main till, so a voucher sold on another till can be opened and topped up.

## Improved

- **Stronger PIN lock:** Repeated wrong PINs now lock the till for longer each time, from 30 seconds up to 15 minutes, and guesses made all at once no longer get past the limit. The "too many attempts" message no longer promises a 30-second wait.
- **Manager PIN checks:** Actions that ask for a manager PIN now first check that you are signed in with permission for that action, so a cashier can no longer use up the PIN attempts.
- **Item counts in your language:** The number of items shown on category tiles and in the category lists now uses the correct plural form, for example in Arabic.
- **Help names my.universaltill.com:** The help pages now name my.universaltill.com instead of calling it "the shop's cloud manager" or "the shop's cloud page".

## Fixed

- **Camera window on small screens:** On a short, wide screen, the Close button of the barcode scanner and camera windows could be pushed off the bottom of the screen. It now always stays visible.
- **Voiding a gift voucher sale on an additional till:** An additional till now refuses to void a sale that sold or topped up a gift voucher, and says why. Nothing is changed, so the voucher balance on the main till keeps matching what your customer holds.
- **Held top-up reason:** When the main till refuses to credit a gift voucher for a specific item, the reason on the held-sales page now appears in your language instead of English.
- **Restoring an iPhone or iPad backup:** The till's secret keys are no longer included in the device backup. If a backup is restored onto another device, the till now notices, resets its cloud connection so that two tills never share one identity, and shows a "connect again" notice in the status bar. Selling carries on and no sales are changed. Saved plugin passwords that cannot be read after a restore ask you to enter them again.
