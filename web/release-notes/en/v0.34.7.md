## New

- **Top up a gift voucher:** on a voucher's page, enter the amount to add and the top-up goes into the basket as a sale. Once it is paid, the voucher's balance grows by that amount.
- **Change the network security key:** a manager can now press **Change key** under **Network security key** on the main till's Tills page, for example after a till was lost. The linked tills receive the new key at once; the main till switches to it at its next restart once they all have it.

## Improved

- **Catalogue locked up front on an additional till:** while an additional till can't reach your main till, the catalogue fields you can't save are greyed out before you start typing, instead of refusing your changes when you press Save. Search, filters, label printing and photos still work.
- **Even safer connection between your tills:** once every till in your shop uses the secure connection, the main till stops accepting new unencrypted pairings, and a new till joining with a pairing code now connects securely from the start. Satellite tills (kiosks, table-QR or order stations) only ever join over the secure connection. The connection's security key can also be renewed automatically after several years, without pairing your tills again.
- **Clearer AI image settings:** the AI Assistant settings now warn you when the image address is not a valid web address, instead of failing later.

## Fixed

- **Receipts readable in the dark theme:** the on-screen receipt after a payment now uses the theme's colours, so its text is no longer light grey on white. Printed receipts are unchanged.
- **Clearer message in percentage fields:** a percentage field with an invalid value now asks for a percentage (for example 7.5 or 7,25) instead of showing the message meant for money amounts.
