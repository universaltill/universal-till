## New

- **Cloud manager reports, printed on the till:** pick Print on a report in your cloud account and send it straight to a chosen till's receipt printer.
- **Catalog changes from any till:** admins and managers can now change items, prices, variants, categories and quick-sale buttons from any till in the shop, not just the main one. The change is saved on the main till and reaches every till within a second. If the main till can't be reached, the change is refused with a clear message instead of being lost, and a change made somewhere else while you were editing is caught before it can overwrite what you typed.

## Fixed

- **Resumed orders:** starting a new sale right after resuming a held, table or pay-at-counter order no longer drops it without a trace — it's now recorded.
- **Pay-at-counter orders entered by hand:** resuming a second order over one whose items were all entered by hand (no scanned items) no longer silently loses it, and holding such an order is no longer refused as empty.
- **Setup wizard:** step 3 now shows the "still installing in the background" note while your tax plugin install is queued, instead of showing nothing.
- **Demo mode:** the status bar's connection check no longer makes any network call while demo mode is on.
- **Plugin security:** a plugin can no longer send scheduled jobs or events under another plugin's identity.
