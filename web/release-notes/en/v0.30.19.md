## New

- **See your subscription status at a glance:** Settings now has a Subscription card showing your plan, status and renewal date. If a paid feature is paused because the subscription couldn't be confirmed or has ended, a short notice explains which features are affected and how to fix it — selling is never affected.

## Improved

- **Unpaid shops' tills don't sync with the cloud:** a till that isn't on a paid plan checks in only when someone on it registers it, pairs it, installs a plugin or presses Check for a paid plan, and it no longer shows a connection problem.

## Fixed

- **A broken payment plugin no longer lets a sale through unchecked:** if a payment method's plugin failed to load, a sale using it could complete without the plugin ever being asked to approve it. That payment method is now refused instead, the same protection already in place for a payment method that was never set up.
- **Switching a till's role no longer raises a false warning:** promoting an additional till to become the shop's main till (or the other way around) no longer shows a confusing device-conflict warning.
