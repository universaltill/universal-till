## New

- **Join as Main till with a code:** during first setup, a new till can now join your shop as its Main till using the pairing code from your my. account.

## Improved

- **Setup language drop-down:** the first-setup screen now offers the language as a drop-down list, with your computer's language already chosen.
- **Import reads more CSV files:** the catalog import now accepts CSV files separated by commas, semicolons or tabs, including files saved with a byte-order mark, such as exports from Epos Now.
- **Receipts in the customer's language:** on a self-order kiosk, the receipt prints in the language the customer picked, and so does the cashier's Print button for that sale.
- **Plan name:** the chain plan now shows as "Multi-location".

## Fixed

- **Day close counts cleared baskets:** baskets cleared with New sale before payment now appear in the day-close figures, and a satellite till's cleared baskets reach the Main till.
- **Import links:** each imported item now keeps its own link back to the source system.
