## Improved

- **No second gift voucher item after an import:** when a new shop imports its own catalogue and that catalogue already has a gift voucher item, the **Gift voucher** item added at setup is now removed, so the sale screen shows only one. It is removed only if it was never used or changed.
- **Safer connection between your tills:** once an additional till has connected to your main till over the secure connection, the main till no longer accepts an unencrypted connection from it.

## Fixed

- **Invoices fit on a phone:** on the invoice list and on a single invoice, the buttons next to the title now wrap below it on a phone, so the title is no longer squeezed.
- **Status and Lock reachable from the keyboard:** while an editing window (such as a new category) is open, the status bar and **Lock** can now be reached with the keyboard, not just by tapping.
