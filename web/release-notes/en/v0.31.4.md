## New

- **Low-disk warning and clean-up:** when the till's storage runs low, managers see a **Storage almost full** warning in the status bar. Within the hour the till cleans up: it keeps only the newest 3 backups and removes leftover update downloads, unsent problem reports and extra restore copies older than a day. Selling is never interrupted; if space is still short, the warning stays until you free some on the device. Backups also never take more than a quarter of the free space (the newest 3 are always kept).

## Fixed

- **Backup problems survive a restart:** if the newest daily backup is missing photos the shop has, the till keeps reporting it in the back office even after a restart or update, until a complete backup is made. A daily backup that fails completely is now reported as a problem too, instead of only being written to the log.
- **Backup names stay readable in problem reports:** the name of a backup file is no longer hidden as if it were a card number.
- **Menu tiles and Docs buttons for plugin pages follow permissions:** a plugin page that appears inside another screen (such as Reports) no longer shows its menu tile or Docs button to staff who aren't allowed to open that screen.
