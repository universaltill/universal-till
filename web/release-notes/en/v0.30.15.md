## Improved

- **Android app:** if the till hits an unexpected error while starting up in the Android app, it now records the error in its log (with passwords and keys hidden) instead of stopping without a trace.

## Fixed

- **Self-order:** a guest scanning a table's QR code while the till is too busy to start a new order now sees "We can't start a new order right now" and is asked to wait a minute. Before, they were told the table was already in use, even when it was free.
