## New

- **A guided tour of the sale screen:** the first time each signed-in person opens the sale screen, small pop-ups point at the menu, products, search, basket, payment and status bar and explain each one. Tap Next to move on, or Skip tour to start selling. You can take the tour again any time from Help.
- **A clear start for your products:** after setup, the till opens on the Import page with three explained ways to begin: import a file from your old till (CSV, Excel or a backup), load sample data to try things out, or skip and add items yourself. Sample data can now be loaded any time from Catalog → Import, and removed from Settings → Data.

## Improved

- **Shorter setup:** the setup wizard no longer asks about sample data or importing; those choices now wait on the Import page after you sign in.
- **Tills without a paid plan check in less:** such a till now checks in with the cloud only when it starts after being installed or updated, and at its first start of the day, instead of repeatedly.

## Fixed

- **Subscription card wording:** a subscription cancelled at the end of its period now shows "paid until" instead of "renews".
- **Promotions on a phone-sized till:** the promotions list now fits the screen instead of running off its edge.
