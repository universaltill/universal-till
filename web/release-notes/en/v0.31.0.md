## New

- **Switch off dine-in/takeaway:** a shop that doesn't sell food or drink to eat in — an off-licence, a barber, a clothes shop — can now choose **Off** under Settings → Dine-in/takeaway prompt. The dine-in/takeaway choice disappears from the sell screen and the self-order kiosk, and the end-of-day report leaves out its "By order type" section. New shops set up as a retail shop or service trade start with Off; existing shops keep their current setting.
- **Choose a till's role when it joins:** when a till joins your main till, pick **Additional till** (works offline and rings up sales like any other till) or **Satellite** (a kiosk, table-QR or order station that needs the main till) under **Join as**. The main till's Tills page shows each till's role, and a manager can change it later with **Change role**. A satellite can only run the self-order screen; if you switch an additional till to self-order, it first asks **Make this a satellite?**
- **Richer plugin pages:** plugins can now show their own pages inside the till in the till's own look, run longer tasks with a progress bar and a **Check progress** link, keep their own files within their storage limit, and read sales and stock summaries only when you have given them that permission.

## Improved

- **Faster plugin start on Raspberry Pi tills:** after the first start, plugins load from a saved copy instead of being rebuilt every time. On a Raspberry Pi 4 that is about half a second per plugin instead of around ten seconds, so the till is ready much sooner after a restart.
- **Inventory shows every item:** the Inventory page now lists every stock-tracked item, including ones you have never received stock for (they show 0 at your Main location); tap a row to receive or adjust stock. The separate add button and the "Manager override — negative stock" and "Process a return" panels are gone; take returns through Journal → Refund or the sell screen.
- **Clear reasons when a setting can't be saved:** when a setting is refused, the till now shows the actual reason right next to it — for example that the main till can't be reached — instead of a general "Could not save" message.
- **Quieter in the background:** the till no longer checks the plugin catalogue every 15 minutes — it refreshes when you open a page that shows it — and the online status light checks the connection once a minute, so it can take up to a minute to change.
- **Shop country on registration:** when the till registers with the Universal Till cloud, it now also sends your shop's country. The consent text in the setup wizard and under Settings → Till registration says so.
- **Safer plugins:** a plugin now needs its own permission before it can reach other devices on your shop's network. If you use the Webhook / ERP Connector plugin to send to a device in your shop, grant it the new local network permission after updating it. Plugins can also never take over more of the till's own pages, and an older plugin page that can't open no longer shows a menu tile or Docs button that leads nowhere.

## Fixed

- **Negative amounts:** a negative amount now starts with its sign, for example -£42.50 instead of £-42.50, and the sign sits on the correct side in Arabic and Persian too.
- **Signing outage override with several tills:** granting a temporary override while the signing device (TSE) is failing now has to be done on the main till, and every till follows it. Before, a grant on an additional till was quietly undone at the next sync; now that till says to use the main till instead.
- **Tax plugins sign in less often:** tax plugins that sign in to HMRC or to a signing service now see the real time, so they reuse a valid sign-in instead of treating it as expired.
