## Neu

- **Abonnementstatus auf einen Blick:** Die Einstellungen zeigen jetzt eine Abonnement-Karte mit Plan, Status und Verlängerungsdatum. Ist eine bezahlte Funktion pausiert, weil das Abonnement nicht bestätigt werden konnte oder abgelaufen ist, erklärt ein kurzer Hinweis, welche Funktionen betroffen sind und wie man das behebt — der Verkauf ist davon nie betroffen.

## Verbessert

- **Kassen unbezahlter Geschäfte synchronisieren nicht mit der Cloud:** Eine Kasse ohne kostenpflichtigen Tarif meldet sich nur, wenn jemand an ihr sie registriert, koppelt, ein Plugin installiert oder auf „Nach einem kostenpflichtigen Tarif suchen“ tippt, und sie zeigt kein Verbindungsproblem mehr an.

## Behoben

- **Ein defektes Zahlungs-Plugin lässt einen Verkauf nicht mehr ungeprüft durch:** Konnte das Plugin einer Zahlungsmethode nicht geladen werden, konnte ein Verkauf mit dieser Methode abgeschlossen werden, ohne dass das Plugin je um seine Zustimmung gebeten wurde. Diese Zahlungsmethode wird jetzt stattdessen abgelehnt — derselbe Schutz, der bereits für eine nie eingerichtete Zahlungsmethode gilt.
- **Der Rollenwechsel einer Kasse löst keine falsche Warnung mehr aus:** Wird eine Zusatzkasse zur Hauptkasse des Geschäfts befördert (oder umgekehrt), erscheint dafür keine verwirrende Gerätekonflikt-Warnung mehr.
