## Neu

- **Andere Kasse von der Hauptkasse aus aktualisieren:** Auf der Seite „Kassen“ der Hauptkasse kann ein Manager für jede verbundene Kasse, die eine ältere Version hat, auf **Jetzt aktualisieren** tippen – auch wenn automatische Updates auf dieser Kasse ausgeschaltet sind. Die verbundene Kasse lädt und installiert genau die Version der Hauptkasse, sobald auf ihr kein Verkauf offen ist; schlägt das fehl, drücken Sie **Jetzt aktualisieren** erneut.
- **Plugins können Dateien annehmen:** Eine Plugin-Seite kann Sie jetzt bitten, eine Datei auszuwählen, etwa ein Foto – bis zu einer Größe, die das Plugin festlegt.
- **Plugins können nach Zeitplan laufen:** Ein Plugin, dem Sie die Zeitplan-Berechtigung gegeben haben, kann jetzt selbstständig kleine Aufgaben in einem vom Plugin festgelegten Abstand erledigen – bis zu alle halbe Minute. Während Verkäufe abgeschlossen werden, wartet es, es bremst nie einen Verkauf, und es hört sofort auf, wenn Sie das Plugin deaktivieren oder entfernen oder ihm die Berechtigung entziehen.

## Verbessert

- **Sicherungen enthalten Ihre Fotos:** Jede Sicherung enthält jetzt auch die Fotos, die Sie für Artikel und Kategorien hochgeladen haben, und Ihr Belegslogo. Beim Wiederherstellen — auch auf einem neuen Gerät — kommen sie zurück, und die eine heruntergeladene Datei ist die ganze Sicherung.

## Behoben

- **Ältere Kassenregistrierungen behalten ihre Cloud-Anmeldung:** Eine Kasse mit einer älteren gemeinsamen Registrierung erhält jetzt auch dann ihre eigene Anmeldung von der Cloud, wenn das Abonnement des Geschäfts nicht aktiv ist. So verbindet sie sich von selbst wieder, sobald das Abonnement wieder aktiv ist, statt dass ihre Anmeldung später abgelehnt wird.
