## Neu

- **Andere Kasse von der Hauptkasse aus aktualisieren:** Auf der Seite „Kassen“ der Hauptkasse kann eine Führungskraft für jede verbundene Kasse, die eine ältere Version hat, auf **Jetzt aktualisieren** tippen. Die verbundene Kasse installiert genau die Version der Hauptkasse; schlägt das fehl, versucht es dieselbe Schaltfläche erneut.
- **Plugins können Dateien annehmen:** Eine Plugin-Seite kann Sie jetzt bitten, eine Datei hochzuladen, etwa eine Preisliste — bis zu einer Größe, die das Plugin festlegt.
- **Plugins können nach Zeitplan laufen:** Ein Plugin, dem Sie die Zeitplan-Berechtigung gegeben haben, kann jetzt alle paar Minuten selbstständig kleine Aufgaben erledigen. Es läuft nie mitten in einem Verkauf und hört sofort auf, wenn Sie das Plugin deaktivieren oder entfernen.

## Verbessert

- **Sicherungen enthalten Ihre Fotos:** Jede Sicherung enthält jetzt auch die Fotos, die Sie für Artikel und Kategorien hochgeladen haben, und Ihr Belegslogo. Beim Wiederherstellen — auch auf einem neuen Gerät — kommen sie zurück, und die eine heruntergeladene Datei ist die ganze Sicherung.

## Behoben

- **Ältere Kassenregistrierungen bleiben verbunden:** Eine Kasse mit einer älteren gemeinsamen Registrierung wechselt jetzt auf ihre eigene Anmeldung, wenn das Geschäft kein Abonnement hat, statt von der Cloud getrennt zu werden.
