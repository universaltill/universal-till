## Verbessert

- **Wareneingang aus my.:** Im Formular „Bestand anpassen“ in my. können Sie jetzt den Lagerort wählen, ob es ein Wareneingang oder eine Korrektur ist, und optional einen Einkaufspreis angeben. Die Kasse verbucht es als normale Lagerbewegung.
- **Nutzungsbedingungen bei der Registrierung:** Beim Registrieren einer Kasse in der Cloud müssen Sie jetzt ein Häkchen setzen, dass Sie die Cloud-Nutzungsbedingungen von Universal Till akzeptieren; ein Link führt zum Text. Ohne Häkchen wird nichts gesendet.
