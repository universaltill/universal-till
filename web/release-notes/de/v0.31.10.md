## Neu

- **Hintergrund eines Fotos ohne zusätzliche Einrichtung entfernen:** Die Fotoauswahlen für Artikel, Kategorien und Varianten bieten jetzt auf jeder Kasse **Hintergrund entfernen** an. Das läuft direkt auf dem Gerät und funktioniert auch offline, Sie brauchen also keinen eigenen Dienst zur Hintergrundentfernung mehr; ist einer eingerichtet, nutzt die Kasse weiterhin diesen. Verarbeitet wird erst, wenn Sie darauf tippen. Auf einer kleinen Kasse kann es etwa 15 Sekunden dauern.
- **KI-Assistenten fragen, bevor sie etwas ändern:** Ein KI-Assistent-Plugin kann einen neuen Artikel oder eine Bestandskorrektur nur vorschlagen. Die Kasse zeigt Ihnen die Änderung und übernimmt sie erst, wenn Sie bestätigen. Eine Kassiererin oder ein Kassierer kann sie nicht bestätigen.

## Verbessert

- **Sie bestimmen, was ein KI-Assistent lesen darf:** Ein KI-Assistent-Plugin braucht Ihre Erlaubnis für jede Art von Geschäftsdaten, die es liest, und das Entziehen einer Erlaubnis wirkt sofort. Neue KI-Berechtigungen werden bei Installation oder Update eines Plugins nicht automatisch eingeschaltet.
- **Plugin-Bereiche auf dem Verkaufsbildschirm:** Die Schaltfläche eines Plugins auf dem Verkaufsbildschirm kann jetzt den eigenen Bereich des Plugins neben dem Verkauf öffnen, ohne ihn zu verlassen. Ein Plugin kann einer Kassiererin oder einem Kassierer außerdem weniger zeigen als einer Filialleitung.

## Behoben

- **Kategorienamen auf Smartphones:** Auf einem Smartphone stehen die Kategorie-Kacheln auf dem Verkaufsbildschirm jetzt zu zweit in einer Reihe, sodass ein Name wie „Haushaltswaren“ nicht mehr mitten im Wort umbricht.
- **Prozent-Aktionen im Zahlenformat Ihrer Sprache:** Auf einer Kasse in einer Sprache mit Dezimalkomma (z. B. Deutsch oder Türkisch) wird eine Prozent-Aktion jetzt als 7,50 statt 7.50 angezeigt und vorausgefüllt.
