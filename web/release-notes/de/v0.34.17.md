## Verbessert

- **Kürzerer Beitritt zu einem Shop:** Hat der Shop, dem Sie von my. aus beitreten, bereits eine Branche, fragt der Einrichtungsassistent nicht noch einmal danach.
- **Keine zweite Anmeldung:** Eine Kasse, die einem my.-Shop beigetreten ist, wird im letzten Schritt des Assistenten nicht mehr zur Registrierung aufgefordert.

## Behoben

- **Cloud-Änderungen werden nur einmal angewendet:** Wurde eine von my. gesendete Änderung nach einer Netzstörung wiederholt, konnte die Kasse sie doppelt anwenden. Jede Änderung wird jetzt genau einmal angewendet.
