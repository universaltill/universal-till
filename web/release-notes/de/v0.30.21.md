## Neu

- **Vollbild unter Windows:** Die Windows-Kasse geht jetzt wirklich in den Vollbildmodus. Im Modus Vollbild oder Kiosk gibt es keine Titelleiste, und die Taskleiste ist ausgeblendet. „Zum Betriebssystem wechseln“ (mit Manager-PIN) oder Alt+F4 bringt Sie jederzeit zurück zum Windows-Desktop. Eine neue Installation öffnet im Vollbild und startet, sobald Sie sich bei Windows anmelden. Ein Update behält Ihre bisherige Wahl bei, und Sie können beides unter Einstellungen → Anzeige ändern.

## Verbessert

- **Plugins entfernen gelöschte Kunden ebenfalls:** Wenn Sie einen Kunden aufgrund einer Datenschutzanfrage löschen, werden Plugins, die eine eigene Kopie dieses Kunden führen (etwa Treueprogramme oder CRM-Anbindungen), jetzt aufgefordert, sie zu löschen.
