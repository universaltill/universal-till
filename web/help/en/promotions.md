# Promotions & promo codes

Create, edit and deactivate the promo codes cashiers scan or type at checkout to apply a discount.

## How to use it

1. Open Promotions to see every code, active and inactive. Type in the search box to narrow the list by code, description or customer name. The Valid column shows the start date above the end date; a dash means no limit on that side.
2. Tap **+** next to the search box to create a code. A dialog opens with the code, the type (amount off or percent off), the value, an optional description, an optional start and end date, and an optional customer to target it at — leave the customer blank so any customer can redeem it. A percent-off value is between 0 and 100, and an end date includes the whole of that day. An amount-off or percent-off value can be typed with a dot or a comma before the decimals (3.50 or 3,50; 7.5 or 7,5). A percent-off value takes at most two decimals (`12.25` is fine, `12.125` is refused). Tap **Save** to create it; if something is wrong, the reason shows in the dialog and nothing you typed is lost.
3. To edit a code, tap its row or the pencil at the end of the row. You can change the type, value, description, dates and the customer at any time. To change the customer, type a name in the customer field and choose one from the search results; to let any customer use the code, tap **×** next to the field to remove the customer. If you type a name but don't choose a result, Save is refused so nothing changes by accident. A code whose customer has been deleted from this till shows *Deleted customer*; choose another customer or remove it. When a customer is erased (Settings → Data management → Erase a customer (GDPR)), every code tied to them is switched off at the same time and shows no customer, so it never becomes a code for everyone. Before you activate it again, choose the customer it is meant for; otherwise any customer can redeem it. The code itself is fixed once created and is shown greyed out.
4. To stop a code working at checkout without losing its history, open it and tap the bin icon, then confirm. Inactive promotions stay in the list; open one and tap **Activate** to turn it back on.
5. A code is never deleted outright, so past sales that used it stay intact.
6. After an update, a code that still points at a customer record that no longer exists is switched off once and shows no customer. Before you activate it again, choose the customer it is meant for; otherwise any customer can redeem it.
