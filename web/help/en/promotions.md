# Promotions & promo codes

Create, edit and deactivate the promo codes cashiers scan or type at checkout to apply a discount.

## How to use it

1. Open Promotions to see every code, active and inactive.
2. Create a code with an amount-off or percent-off value, an optional description, an optional start/end date window, and an optional customer to target it at — leave the customer blank so any customer can redeem it.
3. Edit an existing code's type, value, description, dates or customer target at any time; the code itself can't be changed once created.
4. Deactivate a code to stop it working at checkout without losing its history, and reactivate it the same way.
5. A code is never deleted outright, so past sales that used it stay intact.
