# Categories

Categories group your catalog — they're the tabs across the top of the sale screen, the **Category** field on a catalog item, and what kitchen-station routing sorts by. This page is where you create, rename, reorder or deactivate them.

## How to use it

1. Open **Categories** from the menu (manager only). Every category shows its name, how many active items currently use it, and whether it's active.
2. Type a name under **Create category** and save — the new category appears at the end of the list and is immediately available on the catalog item editor's Category field.
3. **Rename** a category at any time; every item already in it keeps its assignment, nothing else changes.
4. Use the **▲** / **▼** buttons to reorder the list — this is also the order categories appear as tabs on the sale screen and rows on the kitchen-routing page.
5. **Deactivate** a category you no longer use instead of deleting it. It disappears from the sale-screen tabs and the kitchen-routing grid, but keeps showing in the catalog item editor's Category field — so an item still assigned to it never loses that assignment — and its row stays here so it can be reactivated later.

## Good to know

- A category with active items still in it can't be deactivated — the button tells you how many items are in the way. Move or deactivate those items first (or reassign them to a different category from the catalog page), then deactivate the category.
- Categories are a flat list — there's no nesting or sub-categories here.
- Categories are shop-wide and always managed from the **main till**: on a joined till, creating, renaming, reordering or deactivating a category shows a message pointing you back to the main till, rather than accepting a change that would only apply locally.
- Deleting a category outright isn't offered from this page — deactivate instead. A category is only ever removed for good when it's deleted on the main till and no other till still needs it.
