# کدهای تخفیف

کدهای تخفیفی را که صندوقدار هنگام پرداخت اسکن یا تایپ می‌کند تا تخفیف اعمال شود، ایجاد، ویرایش و غیرفعال کنید.

## روش استفاده

1. «کدهای تخفیف» را باز کنید تا همهٔ کدها، فعال و غیرفعال، را ببینید.
2. کدی با مقدار تخفیف ثابت یا درصدی، توضیح اختیاری، بازهٔ تاریخ شروع/پایان اختیاری و مشتری اختیاری برای هدف‌گیری بسازید — برای اینکه هر مشتری بتواند از آن استفاده کند، فیلد مشتری را خالی بگذارید. مقدار درصدی بین ۰ تا ۱۰۰ است و تاریخ پایان شامل تمام آن روز می‌شود.
3. نوع، مقدار، توضیح یا تاریخ‌های یک کد موجود را هر زمان ویرایش کنید؛ خود کد و مشتری هدف آن پس از ایجاد قابل تغییر نیستند.
4. کد را غیرفعال کنید تا بدون از دست رفتن سابقه‌اش در پرداخت کار نکند، و به همان روش دوباره فعالش کنید.
5. هیچ کدی هرگز کاملاً حذف نمی‌شود، پس فروش‌های گذشته‌ای که از آن استفاده کرده‌اند دست‌نخورده می‌مانند.
