# فاکتورها و فاکتور رسمی

برای یک فروش، فاکتور رسمی (مالیاتی) صادر کنید — برای مشتریان تجاری یا هر جا که فاکتور رسمی لازم است.

## روش استفاده

1. فاکتورها را باز کنید، فروش را انتخاب و مشخصات مشتری را وارد کنید.
2. چاپ کنید یا هر فاکتور قبلی را از فهرست دوباره چاپ کنید.
