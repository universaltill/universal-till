# ویرایشگر ترجمه

از **منو ← ترجمه‌ها** (فقط مدیران) می‌توانید متن هر برچسب یا پیام صندوق را به هر یک از زبان‌های صندوق تغییر دهید. زبان را انتخاب کنید، متن را پیدا کنید و نسخه خودتان را بنویسید — با پاک‌کردن یک مورد، متن پیش‌فرض برمی‌گردد.
