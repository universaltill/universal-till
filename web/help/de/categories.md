# Kategorien

Kategorien gruppieren Ihren Katalog — sie sind die Reiter oben am Verkaufsbildschirm, das Feld **Kategorie** an einem Katalogartikel und die Grundlage, nach der das Küchen-Routing sortiert. Auf dieser Seite erstellen, benennen, ordnen oder deaktivieren Sie sie.

## Verwendung

1. Öffnen Sie **Kategorien** über das Menü (nur Manager). Jede Kategorie zeigt ihren Namen, wie viele aktive Artikel sie gerade verwenden und ob sie aktiv ist.
2. Geben Sie unter **Kategorie erstellen** einen Namen ein und speichern Sie — die neue Kategorie erscheint am Ende der Liste und steht sofort im Feld "Kategorie" des Katalogartikel-Editors zur Verfügung.
3. **Benennen Sie eine Kategorie jederzeit um** — jeder bereits zugeordnete Artikel behält seine Zuordnung, sonst ändert sich nichts.
4. Verwenden Sie die Schaltflächen **▲** / **▼**, um die Liste neu zu ordnen — das ist auch die Reihenfolge, in der Kategorien als Reiter am Verkaufsbildschirm und als Zeilen auf der Küchen-Routing-Seite erscheinen.
5. **Deaktivieren** Sie eine Kategorie, die Sie nicht mehr verwenden, statt sie zu löschen. Sie verschwindet aus den Reitern am Verkaufsbildschirm und aus dem Küchen-Routing-Raster, bleibt aber im Feld "Kategorie" des Katalogartikel-Editors sichtbar — damit ein Artikel, der ihr noch zugeordnet ist, diese Zuordnung nicht verliert —, und ihre Zeile bleibt hier stehen, damit sie später reaktiviert werden kann.

## Gut zu wissen

- Eine Kategorie mit noch aktiven Artikeln kann nicht deaktiviert werden — die Schaltfläche zeigt an, wie viele Artikel im Weg stehen. Verschieben oder deaktivieren Sie diese Artikel zuerst (oder ordnen Sie sie auf der Katalogseite einer anderen Kategorie zu), dann deaktivieren Sie die Kategorie.
- Kategorien sind eine flache Liste — es gibt hier keine Verschachtelung oder Unterkategorien.
- Kategorien gelten shopweit und werden immer über die **Hauptkasse** verwaltet: An einer angeschlossenen Kasse zeigt das Erstellen, Umbenennen, Neuordnen oder Deaktivieren einer Kategorie eine Meldung, die auf die Hauptkasse verweist, statt eine Änderung anzunehmen, die nur lokal gelten würde.
- Eine Kategorie endgültig löschen ist auf dieser Seite nicht möglich — deaktivieren Sie sie stattdessen. Eine Kategorie wird nur endgültig entfernt, wenn sie an der Hauptkasse gelöscht wird und keine andere Kasse sie noch benötigt.
