# Kategorien

Kategorien gruppieren Ihren Katalog — sie sind die Reiter oben am Verkaufsbildschirm, das Feld **Kategorie** an einem Katalogartikel und die Grundlage, nach der das Küchen-Routing sortiert. Auf dieser Seite erstellen, benennen, ordnen oder deaktivieren Sie sie.

## Verwendung

1. Öffnen Sie **Kategorien** über das Menü (nur Manager). Jede Kategorie zeigt ihren Namen, wie viele aktive Artikel sie gerade verwenden und ob sie aktiv ist.
2. Tippen Sie auf die Schaltfläche **+** neben dem Suchfeld, um eine Kategorie hinzuzufügen. Ein Vollbild-Formular öffnet sich: Geben Sie den Namen ein und tippen Sie auf **Speichern**. Die neue Kategorie erscheint am Ende der Liste und steht sofort im Feld "Kategorie" des Katalogartikel-Editors zur Verfügung.
3. Tippen Sie auf die Zeile einer Kategorie (oder auf ihre Stift-Schaltfläche), um sie zu bearbeiten. Dasselbe Formular öffnet sich mit ausgefülltem Namen — ändern Sie ihn und tippen Sie auf **Speichern**; jeder bereits zugeordnete Artikel behält seine Zuordnung, sonst ändert sich nichts.
4. Verwenden Sie die Pfeil-Schaltflächen nach oben und unten in einer Zeile, um die Liste neu zu ordnen — das ist auch die Reihenfolge, in der Kategorien als Reiter am Verkaufsbildschirm und als Zeilen auf der Küchen-Routing-Seite erscheinen.
5. Um eine Kategorie stillzulegen, die Sie nicht mehr verwenden, öffnen Sie sie und tippen Sie oben im Formular auf die Papierkorb-Schaltfläche. Sie wird deaktiviert, nicht gelöscht: Sie verschwindet aus den Reitern am Verkaufsbildschirm und aus dem Küchen-Routing-Raster, bleibt aber im Feld "Kategorie" des Katalogartikel-Editors sichtbar — damit ein Artikel, der ihr noch zugeordnet ist, diese Zuordnung nicht verliert —, und ihre Zeile bleibt hier stehen. Um sie zurückzuholen, öffnen Sie sie und tippen Sie auf **Aktivieren**.

## Gut zu wissen

- Tippen Sie in das Suchfeld, um die Liste beim Tippen zu filtern. Passt nichts, sagt die Liste das — leeren Sie die Suche, um wieder alle Kategorien zu sehen.
- Wird das Formular mit ungespeicherten Änderungen geschlossen, fragt es zuerst nach, damit ein versehentliches Tippen auf "Schließen" nie verwirft, was Sie eingegeben haben.
- Eine Kategorie mit noch aktiven Artikeln kann nicht deaktiviert werden — die Meldung zeigt an, wie viele Artikel im Weg stehen. Verschieben oder deaktivieren Sie diese Artikel zuerst (oder ordnen Sie sie auf der Katalogseite einer anderen Kategorie zu), dann deaktivieren Sie die Kategorie.
- Kategorien sind eine flache Liste — es gibt hier keine Verschachtelung oder Unterkategorien.
- Kategorien gelten shopweit und werden immer über die **Hauptkasse** verwaltet: An einer angeschlossenen Kasse zeigt das Erstellen, Umbenennen, Neuordnen oder Deaktivieren einer Kategorie eine Meldung, die auf die Hauptkasse verweist, statt eine Änderung anzunehmen, die nur lokal gelten würde.
- Eine Kategorie endgültig löschen ist auf dieser Seite nicht möglich — deaktivieren Sie sie stattdessen. Eine Kategorie wird nur endgültig entfernt, wenn sie an der Hauptkasse gelöscht wird und keine andere Kasse sie noch benötigt.
