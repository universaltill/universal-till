# Kategorien

Kategorien gruppieren Ihren Katalog — sie sind die Reiter oben am Verkaufsbildschirm, das Feld **Kategorie** an einem Katalogartikel und die Grundlage, nach der das Küchen-Routing sortiert. Auf dieser Seite erstellen, benennen, ordnen oder deaktivieren Sie sie.

## Verwendung

1. Öffnen Sie **Kategorien** über das Menü (nur Manager). Jede Kategorie zeigt ihren Namen, wie viele aktive Artikel sie gerade verwenden und ob sie aktiv ist.
2. Tippen Sie auf die Schaltfläche **+** neben dem Suchfeld, um eine Kategorie hinzuzufügen. Ein Vollbild-Formular öffnet sich: Geben Sie den Namen ein, wählen Sie optional eine **Farbe** (dieselbe feste Palette wie die Kachelfarbe eines Artikels — sie erscheint auf dem Reiter der Kategorie am Verkaufsbildschirm und neben ihrem Namen in dieser Liste), wählen Sie optional ein **Bild** (siehe unten), haken Sie die **Anpassungsgruppen** an, die jeder Artikel der Kategorie anbieten soll, und die **Küchenstationen**, an denen ihre Artikel gedruckt werden, und tippen Sie dann auf **Speichern**. Die neue Kategorie erscheint am Ende der Liste und steht sofort im Feld "Kategorie" des Katalogartikel-Editors zur Verfügung.
3. Tippen Sie auf die Zeile einer Kategorie (oder auf ihre Stift-Schaltfläche), um sie zu bearbeiten. Dasselbe Formular öffnet sich mit ausgefülltem Namen, Farbe, Bild, Gruppen und Stationen — ändern Sie, was nötig ist, und tippen Sie auf **Speichern**; jeder bereits zugeordnete Artikel behält seine Zuordnung, sonst ändert sich nichts.
4. Verwenden Sie die Pfeil-Schaltflächen nach oben und unten in einer Zeile, um die Liste neu zu ordnen — das ist auch die Reihenfolge, in der Kategorien als Reiter am Verkaufsbildschirm und als Zeilen auf der Küchen-Routing-Seite erscheinen.
5. Um eine Kategorie stillzulegen, die Sie nicht mehr verwenden, öffnen Sie sie und tippen Sie oben im Formular auf die Papierkorb-Schaltfläche. Sie wird deaktiviert, nicht gelöscht: Sie verschwindet aus den Reitern am Verkaufsbildschirm und aus dem Küchen-Routing-Raster, bleibt aber im Feld "Kategorie" des Katalogartikel-Editors sichtbar — damit ein Artikel, der ihr noch zugeordnet ist, diese Zuordnung nicht verliert —, und ihre Zeile bleibt hier stehen. Um sie zurückzuholen, öffnen Sie sie und tippen Sie auf **Aktivieren**.

## Gut zu wissen

- Tippen Sie in das Suchfeld, um die Liste beim Tippen zu filtern. Passt nichts, sagt die Liste das — leeren Sie die Suche, um wieder alle Kategorien zu sehen.
- Wird das Formular mit ungespeicherten Änderungen geschlossen, fragt es zuerst nach, damit ein versehentliches Tippen auf "Schließen" nie verwirft, was Sie eingegeben haben.
- Eine Kategorie mit noch aktiven Artikeln kann nicht deaktiviert werden — die Meldung zeigt an, wie viele Artikel im Weg stehen. Verschieben oder deaktivieren Sie diese Artikel zuerst (oder ordnen Sie sie auf der Katalogseite einer anderen Kategorie zu), dann deaktivieren Sie die Kategorie.
- **Anpassungsgruppen einer Kategorie werden vererbt:** Jeder Artikel der Kategorie bietet sie beim Hinzufügen zu einem Verkauf an, zusammen mit den direkt am Artikel angehängten Gruppen, ohne Kopie pro Artikel — ändern Sie die Gruppen der Kategorie, folgen alle Artikel sofort. Ein Artikel kann eine der vererbten Gruppen in seinem eigenen Editor überspringen (Artikel → der Artikel → Reiter Varianten → Anpassungsgruppen verwalten → *Für diesen Artikel überspringen*); das betrifft nur diesen Artikel. Die Gruppen selbst werden unter **Anpassungsoptionen** angelegt; diese Seite wählt nur aus den bereits vorhandenen aus.
- **Das Küchen-Routing folgt derselben Regel wie die Seite Küchenstationen:** Ein Artikel druckt an seinen eigenen Stationen, falls er welche hat, sonst an den Stationen seiner Kategorie, sonst am Standard-Küchendrucker. Stationen hier anzuhaken ist dasselbe wie die Zeile der Kategorie auf der Seite Küchenstationen anzuhaken; die eigene Übersteuerung eines Artikels wird im Reiter Varianten seines Editors (oder auf der Seite Küchenstationen) gesetzt und gewinnt immer vollständig — sie ergänzt die Stationen der Kategorie nicht.
- **Kategoriebilder:** Das Bild einer Kategorie erscheint auf ihrer Kachel am Verkaufsbildschirm (Art des Stöberns *Kategoriekacheln*), auf ihrem Reiter in der Kategorieleiste und in der **…**-Liste aller Kategorien. Tippen Sie im Formular auf eines der integrierten Bilder, laden Sie mit **Foto aufnehmen** oder **Datei auswählen** ein Foto hoch (PNG oder JPEG), oder tippen Sie auf **Kein Bild** — ein integriertes Bild und ein hochgeladenes Foto ersetzen einander. Kategoriekacheln bleiben in jedem Fall kompakt: oben das Bild, darunter Name und Artikelanzahl. Eine angeschlossene Kasse zeigt die integrierten Bilder ebenfalls, ein hochgeladenes Foto bleibt vorerst aber an der Hauptkasse — dort zeigt die Kategorie nur ihren Namen.
- Kategorien sind eine flache Liste — es gibt hier keine Verschachtelung oder Unterkategorien.
- Kategorien gelten shopweit und werden immer über die **Hauptkasse** verwaltet: An einer angeschlossenen Kasse zeigt das Erstellen, Umbenennen, Neuordnen oder Deaktivieren einer Kategorie eine Meldung, die auf die Hauptkasse verweist, statt eine Änderung anzunehmen, die nur lokal gelten würde.
- Eine Kategorie endgültig löschen ist auf dieser Seite nicht möglich — deaktivieren Sie sie stattdessen. Eine Kategorie wird nur endgültig entfernt, wenn sie an der Hauptkasse gelöscht wird und keine andere Kasse sie noch benötigt.
