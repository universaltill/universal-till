# Übersetzungseditor

Öffnen Sie **Menü → Übersetzungen** (nur Manager), um zu ändern, wie eine Beschriftung oder Meldung auf der Kasse formuliert ist, in jeder Sprache der Kasse. Wählen Sie eine Sprache, finden Sie den Text, tippen Sie Ihre Version ein — ein geleertes Feld geht zur eingebauten Formulierung zurück.

Es gibt Tausende von Texten in der Kasse, daher wird die Liste seitenweise geladen und beim Herunterscrollen automatisch weiter geladen. Die Suche durchsucht immer die gesamte Liste, nicht nur das bereits Geladene.
