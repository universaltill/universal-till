# Mehrere Kassen (ein Geschäft)

Betreiben Sie mehrere Kassen im selben Geschäftsnetzwerk: eine ist die Hauptkasse, die anderen treten ihr bei und teilen sich automatisch Katalog, Preise, Einstellungen und Bestand. Fotos, die Sie an der Hauptkasse für Artikel und Kategorien hochladen, folgen innerhalb etwa einer halben Minute, sodass jede Kasse dieselben Bilder zeigt.

## Verwendung

1. Gehen Sie auf der **Hauptkasse** zu Einstellungen → Kassen und lassen Sie sich den Kopplungscode anzeigen. Es ist ein Textblock (oder ein QR-Code), der sowohl die Adresse als auch ein Einmal-Token enthält.
2. Installieren Sie auf dem **zweiten Gerät** die Kassen-App. Wählen Sie auf ihrem ersten Einrichtungsbildschirm **Einem bestehenden Geschäft beitreten**. Es gibt zwei Wege, beizutreten: die Hauptkasse automatisch im Netzwerk finden oder den Kopplungscode von Hand einfügen.
3. Geben Sie dieser Kasse oberhalb der beiden Reiter einmalig einen Namen — er ist erforderlich, und das Feld wird rot mit einer Meldung, wenn Sie versuchen zu suchen oder einen Code einzufügen, bevor Sie es ausgefüllt haben. Wählen Sie dann einen Reiter: **In diesem Netzwerk finden** (am einfachsten): Drücken Sie **Primäre Kasse in diesem Netzwerk suchen**, wählen Sie die Hauptkasse aus der Liste, und drücken Sie **Kopplung anfragen**. Beide Bildschirme zeigen jetzt denselben sechsstelligen Code — prüfen Sie, ob sie übereinstimmen, und genehmigen Sie die Anfrage dann auf der Kassenseite der Hauptkasse (das macht ein Manager; das PIN-Feld jeder ausstehenden Anfrage zeigt, zu welchem Gerät sie gehört). Ein Manager muss dafür nicht bereits auf der Kassenseite sein: An der Hauptkasse zeigt eine irgendwo ausstehende Anfrage einen ausblendbaren Hinweis oben auf dem Bildschirm sowie ein Abzeichen am Kassen-Symbol in der Seitenleiste (siehe Schritt 11) — das Ausblenden des Hinweises genehmigt oder lehnt nichts ab, es verbirgt ihn nur, bis eine neue Anfrage eintrifft oder die Kassen-App neu gestartet wird. Schlägt die Kopplung fehl, bleibt der Grund auf dem Bildschirm stehen, bis Sie es erneut versuchen — kein Neuladen der Seite nötig. Die Anfrage läuft nach 10 Minuten ab, wenn sie niemand genehmigt. Oder **Kopplungscode einfügen**: Fügen Sie den **gesamten** Kopplungscode aus Schritt 1 in das Feld „Kopplungscode“ ein und drücken Sie „Beitreten“. Die Adresse der Hauptkasse allein reicht nicht aus — der Code trägt das Einmal-Token, das die Aufnahme autorisiert. Der Name muss im Netzwerk dieses Geschäfts eindeutig sein: Wird der Beitritt abgelehnt, weil der Name bereits verwendet wird (von der Hauptkasse oder einer anderen beigetretenen Kasse), wählen Sie einen anderen Namen und versuchen Sie es erneut.
4. Warten Sie, bis der Vorgang abgeschlossen ist. Dabei wird das gesamte Geschäft kopiert — Katalog, Preise, Einstellungen, Bestand und Bediener —, was in einem geschäftigen Geschäftsnetzwerk bis zu einer Minute dauern kann. Drücken Sie „Beitreten“ nicht zweimal: Das Token ist nur einmal gültig, und ein zweiter Druck schlägt mit „Code bereits verwendet oder abgelaufen“ fehl. Meldet der Bildschirm, dass die Kasse beigetreten ist, endet inzwischen jeder der beiden Reiter gleich: Die Kasse startet sich zum Abschließen selbst neu — der Bildschirm sagt dies, und nach ein paar Sekunden erscheint wieder der Anmeldebildschirm (auch dort gibt es eine Schaltfläche „Jetzt neu starten“ für den Fall, dass es nicht von selbst geschieht). Unter Windows kann sich die Kasse noch nicht selbst neu starten — schließen Sie stattdessen das Fenster und öffnen Sie Universal Till erneut.
5. Schlägt es fehl, erscheint der Grund unter der Schaltfläche. Die häufigsten Ursachen sind, dass die beiden Kassen nicht im selben Netzwerk sind, und dass nur ein Teil des Codes eingefügt wurde.
6. Verkäufe an jeder Kasse fließen zur Hauptkasse zurück, und Katalogänderungen verbreiten sich innerhalb von etwa einer halben Minute an alle Kassen.
7. An einer beigetretenen Kasse sind Katalog und Bestand nur lesbar — ein Banner oben weist darauf hin und verweist auf die Hauptkasse. Unter Windows und Mac ist dieser Banner ein klickbarer Link; in der Kiosk-App ist er stattdessen reiner Text, da der Kiosk keinen Weg zurück hätte, wenn ein Link ihn zum Bildschirm einer anderen Kasse führen würde.
8. Der Bestand wird ausschließlich von der Hauptkasse entschieden. Eine beigetretene Kasse verweigert einen Verkauf nie wegen fehlenden Bestands — ihre eigene Bestandszahl ist nur eine Kopie, die einige Sekunden hinterherhinken kann, sodass sie den Verkauf immer durchlässt. Führt dies dazu, dass der Bestand eines Artikels tatsächlich unter null fällt (zwei Kassen verkaufen fast gleichzeitig den letzten), erscheint dies als Problem im Dashboard der Hauptkasse, statt jemandes Verkauf zu blockieren.
9. Auf der eigenen Kassenseite der **Hauptkasse** zeigt die Liste „Registriert“ auch die Hauptkasse selbst (beschriftet als „diese Kasse“) neben allen beigetretenen Kassen, unter Verwendung des in den Einstellungen festgelegten Namens — sodass auch ein Geschäft mit nur einer Kasse eine Liste sieht und keine leere Tabelle. Auf der Hauptkasse ist diese Liste live — sie aktualisiert sich alle 10 Sekunden von selbst — und jede beigetretene Kasse zeigt, ob sie gerade **Verbunden** oder **Nicht verbunden** ist, ob sie eine zusätzliche Kasse ist, ihre Version im Vergleich zur Hauptkasse, ein wartendes oder fehlgeschlagenes Update, wie viele Verkäufe noch auf das Senden warten und ob ihre gesicherte Verbindung (TLS) fest hinterlegt ist.
10. An einer **beigetretenen Kasse** zeigt die Kassenseite dieselbe geschäftsweite Liste ebenfalls — die Hauptkasse (beschriftet als „die primäre Kasse“) und jede andere beigetretene Kasse, einschließlich sich selbst (beschriftet als „diese Kasse“). Dort ist sie nur lesbar: Nur die Hauptkasse kann eine beigetretene Kasse entfernen („widerrufen“). An **jeder** Kasse — Hauptkasse oder beigetreten — zeigt die Kassenseite außerdem eine Zeile **Cloud-Verbindung** für die eigene Verbindung dieser Kasse zur Cloud — Verbindet, Live, Periodisch, Verbindet erneut, Pausiert oder Gestoppt — jeweils mit einer kurzen Erklärung. Nur die Hauptkasse hält eine Live-Verbindung; eine beigetretene Kasse meldet sich alle paar Minuten selbst bei der Cloud und zeigt daher Periodisch.
11. Der kleine Sync-Chip unten in der linken Navigation zeigt den eigenen Namen dieser Kasse und ist sowohl auf der Hauptkasse als auch auf einer beigetretenen Kasse klickbar — er öffnet die Kassenseite. Er ist ein gewöhnliches Symbol in der Seitenleiste wie jede andere Menütaste — sein Sync-Status ändert NICHT die Farbe der Schaltfläche; stattdessen erscheint ein kleiner Punkt auf dem Symbol, wenn etwas Aufmerksamkeit braucht (sie hat sich länger nicht gemeldet, oder Verkäufe warten auf die Synchronisierung). Ein Geschäft mit nur einer Kasse ohne Beitritte zeigt gar keinen Chip an — es gibt noch nichts zu synchronisieren.
    - Auf der **Hauptkasse** übernimmt der Chip auch denselben Punkt, und sein Link zeigt statt auf die Kassenseite auf die Quarantäneliste, falls eine beigetretene Kasse jemals einen Verkauf sendet, den sie nicht anwenden kann (ein äußerst seltener Grenzfall — zum Beispiel zwei Kassen, die offline denselben Gutscheincode ausstellen). Statt stillschweigend verloren zu gehen, wird dieser eine Verkauf zur Prüfung auf der Seite **Einstellungen → Sync-Quarantäne** der Hauptkasse zurückgehalten, die Kasse, Belegnummer, Grund und Zeitpunkt auflistet. Dies blockiert nie die Synchronisierung eines anderen Verkaufs.
    - Ein Geschenkgutschein funktioniert geschäftsweit: Verkaufen Sie ihn an einer beliebigen Kasse, und er kann an jeder anderen nachgeschlagen und eingelöst werden — solange beide online sind, reserviert die einlösende Kasse den Betrag in Echtzeit auf der Hauptkasse, bevor der Verkauf abgeschlossen wird, sodass er nicht mehr abgelehnt wird, nur weil er woanders verkauft wurde — und zwei Kassen können nicht gleichzeitig dasselbe Guthaben ausgeben: Wer die Hauptkasse als Zweiter erreicht, wird abgelehnt, statt dass der Gutschein überzogen wird. Verliert eine beigetretene Kasse die Verbindung zur Hauptkasse, ist das Einlösen eines Gutscheins, den sie selbst noch nie gesehen hat, weiterhin erst wieder möglich, wenn die Verbindung zurück ist (wie bei jeder anderen von der Hauptkasse abhängigen Aktion); ein Gutschein, den diese Kasse bereits kennt, funktioniert weiterhin offline wie zuvor.
    - Ebenfalls nur auf der **Hauptkasse**: Ein Punkt erscheint auf demselben Chip, während ein Gerät auf die Kopplung wartet (Schritt 3), und sein Titel/Tippziel öffnet weiterhin die Kassenseite (sofern die Quarantäne ihn nicht bereits beansprucht hat). Er verschwindet von selbst, sobald die Anfrage genehmigt, abgelehnt wird oder abläuft — kein Neuladen nötig.
12. Plugins folgen ebenfalls der Hauptkasse: Installieren oder entfernen Sie ein Plugin auf der **Hauptkasse**, übernimmt jede beigetretene Kasse dieselbe Änderung automatisch innerhalb von etwa einer halben Minute. Jede Kasse lädt das Plugin selbst aus dem Plugin-Store herunter und verifiziert es, bevor es läuft — Plugins werden nie von Kasse zu Kasse kopiert. Der Versuch, ein Plugin direkt auf einer beigetretenen Kasse zu installieren, zu entfernen, zu aktivieren, zu deaktivieren oder zu aktualisieren, wird mit einer Meldung abgelehnt, die auf die Hauptkasse verweist. Die eine Ausnahme ist ein aus einer Datei importiertes Plugin: Der Import funktioniert weiterhin auf jeder Kasse, auch einer beigetretenen, das Plugin bleibt jedoch nur auf dieser Kasse und verbreitet sich nicht.

## Register

Ein **Register** ist eine Kassen-/Checkout-Station — das, auf dem eine Schicht eröffnet und ein Verkauf gebucht wird. Ein Geschäft kann mehr als eines haben: zum Beispiel eine vordere und eine hintere Theke, die gleichzeitig Verkäufe aufnehmen.

- Öffnen Sie **Register** über das Menü (nur Manager), um eines anzulegen. Geben Sie ihm einen Namen und optional den Lagerort, aus dem es sich bedient; ein Manager kann es später umbenennen, seinen Lagerort ändern oder es deaktivieren (die Deaktivierung behält seine Verkaufs-/Schichthistorie — sie bietet es lediglich nicht mehr für eine neue Schicht an). Das Ändern des Lagerorts berührt nicht seine vergangenen Verkäufe oder Schichten — diese bleiben an das Register selbst gebunden. Ein Register mit bereits vorhandener Schicht-/Verkaufshistorie zeigt auf dieser Seite den Hinweis „Hat Schicht-/Verkaufshistorie“ — nur informativ, blockiert die Deaktivierung nie.
- Register sind geschäftsweit und werden immer von der **Hauptkasse** aus verwaltet: An einer beigetretenen Kasse zeigt das Anlegen, Umbenennen oder Deaktivieren eines Registers eine Meldung, die Sie zur Hauptkasse zurückverweist, statt eine nur lokal gültige Änderung anzunehmen.
- Der Beitritt einer zweiten Kasse (siehe oben) weist ihr **automatisch** ein Register zu: Die Aufnahme legt auf der Hauptkasse ein neues Register an, benannt nach der beitretenden Kasse (ist dieser Name bereits vergeben, wird eine Zahl angehängt, z. B. „Kasse 2 (2)“), und die beigetretene Kasse startet bereits darauf eingestellt — kein manueller Schritt nötig, und sie kann sofort ihre eigene Schicht eröffnen. Der manuelle Weg bleibt bestehen, wenn Sie mehr möchten: Legen Sie weitere Register unter **Register** an (ein Geschäft kann mehr Register als Kassen haben), benennen Sie eines dort um, oder ändern Sie, auf welchem Register eine Kasse steht, an dieser Kasse unter **Einstellungen → Kassen** → **Register dieser Kasse**.
- Hatte dieses Geschäft ein Register oder einen Lagerort, der direkt an einer beigetretenen Kasse angelegt wurde, bevor beide geschäftsweit geführt wurden, entfernt die nächste Synchronisierung von der Hauptkasse ihn (falls er noch keine Schicht-/Verkaufs- oder Bestandshistorie hat) oder deaktiviert ihn (falls doch) — dieselbe Regel „Primäre gewinnt“ wie oben, die nur diese eine übrig gebliebene Zeile nachholt. Wird das eigene Register einer beigetretenen Kasse dadurch ungültig, wählen Sie unter **Einstellungen → Kassen** → **Register dieser Kasse** erneut ein funktionierendes.

## Wenn eine beigetretene Kasse die Hauptkasse nicht erreicht

1. An einer beigetretenen Kasse hat die Statusleiste unten auf jedem Bildschirm — auch auf dem Verkaufsbildschirm — eine Anzeige für die Hauptkasse, und sie sagt immer in Worten, was sie bedeutet: **Hauptkasse verbunden** (grüner Punkt) heißt, es besteht eine Live-Verbindung: Änderungen an der Hauptkasse kommen innerhalb einer Sekunde an. **Hauptkasse: regelmäßige Abfrage** (leerer Punkt) heißt, es gibt keine Live-Verbindung — meist läuft auf der Hauptkasse eine ältere Version —, Änderungen kommen trotzdem an, innerhalb von etwa 30 Sekunden. **Hauptkasse nicht erreichbar seit … — Verkauf offline** (gelb) heißt, die Hauptkasse ist verstummt: Der Hinweis erscheint etwa 15 Sekunden nach dem Abbruch der Verbindung, ohne Live-Verbindung nach etwa anderthalb Minuten. Die beigetretene Kasse verkauft in jedem Fall weiter — ihre Verkäufe warten auf der beigetretenen Kasse und werden synchronisiert, sobald die Hauptkasse zurück ist. Unterscheiden sich die Versionen, ergänzt die verbundene Anzeige **Update wartet** (diese Kasse ist älter als die Hauptkasse) oder **Warten auf das Update der Hauptkasse** (diese Kasse ist neuer). Warten Plugin-Updates, sagt der gelbe Hinweis das ebenfalls: An einer beigetretenen Kasse folgen Plugins der Hauptkasse und können erst aktualisiert werden, wenn sie wieder erreichbar ist. Die eigene **Online**-Anzeige des Browsers erscheint an einer beigetretenen Kasse nicht daneben — sie wusste nur, dass ein Netzwerkkabel oder WLAN verbunden ist — und zeigt sich als **Kein Internet** nur, wenn das Netzwerk wirklich ausgefallen ist. Tippen Sie auf die Anzeige, um die Kassenseite zu öffnen; sie erklärt denselben Zustand und zeigt in der Zeile der Hauptkasse, wann diese Kasse sie zuletzt erreicht hat.
2. Meist ist nichts zu tun. Ist die Hauptkasse nur unter einer anderen Adresse zurückgekommen (zum Beispiel nach einem Neustart mit neuer Netzwerkadresse oder neuem Port), findet die beigetretene Kasse sie von selbst wieder: Alle paar Minuten sucht sie die Hauptkasse im Geschäftsnetzwerk und verbindet sich nur mit derselben Hauptkasse, mit der sie gekoppelt wurde — diese muss nachweisen, dass sie die Kopplung dieser Kasse besitzt, sodass kein anderes Gerät im Netzwerk ihren Platz einnehmen kann. Die Kopplung bleibt erhalten, nichts wird neu kopiert, und die Anzeige wechselt mit dem nächsten erfolgreichen Kontakt zurück zu **Hauptkasse verbunden** (oder **regelmäßige Abfrage**).
3. Nach einem Neustart kommt die Hauptkasse normalerweise auf demselben Port zurück, daher sollte das selten vorkommen — der Router kann ihr allerdings eine neue Netzwerkadresse geben; darum kümmert sich die Suche aus Schritt 2. Bleibt der Hinweis, prüfen Sie, ob die Hauptkasse eingeschaltet und mit demselben Netzwerk wie diese Kasse verbunden ist.
4. Treten Sie nur erneut bei, wenn die Hauptkasse neu installiert oder ersetzt wurde. Stellen Sie zuerst sicher, dass auf dieser Kasse keine Verkäufe mehr warten (der Sync-Hinweis in der Seitenleiste zeigt die Anzahl wartender Verkäufe), denn ein Beitritt kopiert das ganze Geschäft erneut von der Hauptkasse und ersetzt, was auf dieser Kasse ist. Entfernen Sie dann diese Kasse auf der Seite „Kassen“ der Hauptkasse und nutzen Sie auf dieser Kasse **Einem bestehenden Geschäft beitreten** auf der Seite „Kassen“, wie in Schritt 3 unter „Verwendung“.
