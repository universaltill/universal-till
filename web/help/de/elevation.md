# Manager-Freigabe vor Ort

Manche Aktionen — eine Berechtigung ändern, eine Kasse befördern, eine Sicherung
ausführen, den Tagesabschlussbericht ausführen oder erneut drucken, einen
Benutzer anlegen oder jemandes PIN oder Rolle ändern, und weitere — benötigen
die Zustimmung eines Managers oder Admins. Ist Ihr eigenes Konto dazu nicht
berechtigt, lehnt der Bildschirm nicht einfach ab: Er öffnet direkt vor Ort
eine kleine PIN-Abfrage.

## Verwendung

1. Versuchen Sie die Aktion wie gewohnt. Ist Ihre Rolle dazu nicht berechtigt,
   erscheint ein Dialog, der statt einer einfachen Fehlermeldung nach der PIN
   eines Managers oder Admins fragt.
2. Lassen Sie einen Manager oder Admin seine eigene PIN in diesen Dialog
   eingeben und bestätigen.
3. Ist die PIN korrekt und die betreffende Person tatsächlich zu dieser
   Aktion berechtigt, wird sie sofort ausgeführt — als diese Person, nicht als
   Sie. Niemand meldet sich ab oder wechselt das Konto.
4. Eine falsche PIN, zu viele Versuche oder eine PIN, die jemandem gehört,
   der diese bestimmte Aktion immer noch nicht ausführen darf, zeigen
   allesamt einen klaren Grund im selben Dialog an, damit Sie wissen, was als
   Nächstes zu versuchen ist.

## Was aufgezeichnet wird

Die Aktion wird als vom freigebenden Manager oder Admin durchgeführt protokolliert — genauso
wie alles andere im Prüfprotokoll (Berichte → Prüfprotokoll). Das ursprünglich
blockierte Konto wird ebenfalls in diesem Eintrag festgehalten, sodass die
vollständige Geschichte — wer es versucht hat und wer es tatsächlich
freigegeben hat — nie verloren geht, auch wenn der heutige Prüfprotokoll-Bildschirm
den Namen der freigebenden Person als Akteur des Eintrags anzeigt.
