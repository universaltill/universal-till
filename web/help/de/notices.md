# Mitteilungen

Nachrichten von Universal Till und Ihren Partnern erscheinen in einer Glocke im linken Menü. Sie stören nie einen Verkauf.

## Einschalten

1. Öffnen Sie die Einstellungen und suchen Sie die Karte „Mitteilungen“.
2. Haken Sie „Mitteilungen auf dieser Kasse anzeigen“ an und drücken Sie Speichern.

Mitteilungen sind standardmäßig aus. Solange sie aus sind, gibt es keine Glocke und die Kasse fragt die Cloud um nichts Zusätzliches. Wenn Sie sie wieder ausschalten, werden die auf dieser Kasse gespeicherten Mitteilungen gelöscht. Eine Kasse erhält Mitteilungen nur, solange sie mit der Cloud verbunden ist und das Geschäft einen aktiven Tarif hat.

## Mitteilungen lesen

1. Die Glocke zeigt, wie viele Mitteilungen ungelesen sind; „9+“ heißt neun oder mehr. Ein rotes, eckiges Zeichen mit Dreieck bedeutet, dass eine davon kritisch ist.
2. Tippen Sie auf die Glocke, um den Posteingang zu öffnen. Ungelesen zeigt, was Sie noch nicht geöffnet haben; Alle zeigt alles, was die Kasse hält.
3. Tippen Sie auf eine Mitteilung, um sie zu öffnen. Das Öffnen markiert sie als gelesen. Ausblenden entfernt sie aus Ungelesen; unter Alle bleibt sie, bis sie abläuft.

Jede Mitteilung nennt ihren Absender. Eine Mitteilung von Universal Till trägt den Namen Universal Till; eine von einem Ihrer Partner hat einen gestrichelten Rand und „Von“ mit dem Namen des Partners. Der Text einer Mitteilung wird als einfacher Text mit Fett, Kursiv und sicheren Links angezeigt.

## Hinweise und der kritische Streifen

- Hinweise ändern nur die Glocke. Sie erscheinen nie als Einblendung.
- Eine wichtige Mitteilung erscheint einmal oben über den Artikeln, etwa zehn Sekunden lang. Sie pausiert, solange Sie sie berühren. Sie erscheint nie, solange das Zahlungsfeld offen ist; sie wartet, bis Sie wieder beim Warenkorb sind.
- Eine kritische Mitteilung von Universal Till bleibt als Streifen oben auf jedem Bildschirm, bis ein Manager oder Admin „Zur Kenntnis genommen“ drückt. Das markiert sie nicht als gelesen.

Nichts davon blockiert, verdeckt oder verzögert je einen Verkauf, eine Zahlung oder eine Erstattung. Die Kasse arbeitet weiter offline.

## Wer sie sieht

Manager und Admins sehen die Glocke und den Posteingang. Ein Kassierer sieht sie nicht, es sei denn, ein Admin gibt der Rolle unter Benutzer, Berechtigungen die Berechtigung „Mitteilungen“. Auch ohne sie sieht ein Kassierer eine kritische Mitteilung von Universal Till als reinen Lese-Streifen, der sagt, dass ein Manager informiert wurde und der Verkauf weitergeht.
