# Der Menü-Bildschirm

Tippen Sie auf **☰ Menü** auf dem Verkaufsbildschirm, um eine Seite mit großen Touch-Kacheln zu öffnen — eine für jeden Bereich der Kasse. Tippen Sie auf eine Kachel, um dorthin zu gelangen; tippen Sie auf das Logo, um zum Verkaufen zurückzukehren. Die Pfandrückgabe öffnet sich an Ort und Stelle als kleines Formular, statt wegzunavigieren.
