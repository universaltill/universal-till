# Schnellwahltasten

Ordnen Sie die Schnellwahltasten und das Produktraster auf dem Verkaufsbildschirm an. Die Seite zeigt eine Live-Kopie des Produktbereichs des Verkaufsbildschirms — dieselben Kategorie-Reiter, dieselben Kacheln in derselben Größe — und Sie bearbeiten sie direkt darin; jede Änderung erscheint sofort, es gibt nichts nachträglich zu speichern.

## Verwendung

1. Öffnen Sie „Schnellwahltasten“ und verwenden Sie das Suchfeld unter dem Bereich, um einen Artikel zu finden; tippen Sie ihn an, um ihn als Schnellwahltaste hinzuzufügen — seine Kachel erscheint unter dem Kategorie-Reiter des Artikels.
2. Tippen Sie auf den Stift am Ende der Kategorieleiste (oder halten Sie eine Kachel gedrückt), um den Bearbeitungsmodus zu starten: Kacheln und Kategorie-Reiter wackeln. Ziehen Sie eine Kachel, um sie innerhalb ihrer Kategorie zu verschieben, oder ziehen Sie einen Kategorie-Reiter, um die Reihenfolge der Reiter zu ändern — per Tastatur mit den Pfeiltasten links/rechts auf der fokussierten Kachel bzw. dem Reiter. Das Papierkorb-Symbol an einer Kachel entfernt sie von den Schnellwahltasten (der Artikel bleibt im Katalog). Tippen Sie zum Schluss auf „Fertig“ oder drücken Sie Escape — dann wird die neue Reihenfolge gespeichert.
3. Im Bearbeitungsmodus zeigt jeder Kategorie-Reiter einen kleinen Stift: Tippen Sie darauf, um die Kategorie umzubenennen oder eine Farbe zu wählen, und speichern Sie. Das Papierkorb-Symbol in demselben Fenster deaktiviert die Kategorie — nach einer Rückfrage, und eine Kategorie, in der noch aktive Artikel liegen, wird mit der Anzahl abgelehnt, damit nichts versehentlich verloren geht. Das **+** am Ende der Leiste legt eine neue, zunächst leere Kategorie an.

Schnellwahltasten und Kategorien sind geschäftsweit und werden immer von der **Hauptkasse** aus verwaltet: An einer beigetretenen Kasse zeigt das Hinzufügen, Entfernen oder Neuanordnen einer Schaltfläche oder das Bearbeiten einer Kategorie eine Meldung, die Sie zur Hauptkasse zurückverweist, statt eine nur lokal gültige Änderung anzunehmen.

Dies ist nicht dieselbe Seite wie der **Belegdesigner** (Einstellungen → Belegdrucker → Belegdesigner), der anpasst, was auf Belegen gedruckt wird — siehe [Belegdesigner](/help/designer).

- Auf dem Verkaufsbildschirm selbst gibt es denselben Bearbeitungsmodus für die Kacheln: Halten Sie eine Kachel gedrückt (oder klicken Sie mit der rechten Maustaste), um sie zu verschieben, aus den Schnellwahltasten zu entfernen oder im Katalog zu bearbeiten — ohne diese Seite zu öffnen. Kategorien werden nur hier bearbeitet.
