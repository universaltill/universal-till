# Optionssets

Ein Optionsset ist eine benannte, wiederverwendbare Werteliste — **Größe** mit S, M und L, oder **Farbe** mit Rot, Grün und Blau. Statt „S“, „M“ und „L“ bei jedem T-Shirt im Katalog von Hand einzutippen, legen Sie das Set hier einmal an und wenden es auf beliebige Artikel an; die Kasse erzeugt dann die Varianten dieses Artikels für Sie.

Jede erzeugte Variante ist eine ganz normale Variante: Sie hat eine eigene SKU, einen Preis, Bestand und Barcodes und wird genau wie eine von Hand angelegte verkauft, gedruckt und gezählt.

## Verwendung

1. Öffnen Sie den Katalog und drücken Sie **Optionssets** (neben der Schaltfläche „Anpassungsoptionen“). Geben Sie einen Namen ein — etwa *Größe* — und drücken Sie **Optionsset hinzufügen**.
2. Fügen Sie auf der Karte des Sets die Werte nacheinander mit **Wert hinzufügen** hinzu — *S*, dann *M*, dann *L*. Werte behalten die Reihenfolge, in der Sie sie eingeben; in dieser Reihenfolge werden die Varianten erzeugt.
3. Zurück auf der Katalogseite klicken Sie einen Artikel an, um sein Bearbeitungsfeld zu öffnen. Oberhalb des Variantenrasters haken Sie die gewünschten Optionssets an — **höchstens zwei** (zum Beispiel Größe und Farbe) — und drücken **Speichern**.
4. Drücken Sie **Varianten erzeugen**. Für jede Kombination wird eine Variante angelegt (drei bei Größe allein; Größe × Farbe mit drei Farben ergibt neun), benannt wie *S* oder *S / Rot* (die Werte werden in der Reihenfolge verbunden, in der die Sets auf dieser Seite aufgeführt sind — der Reihenfolge, in der Sie sie angelegt haben), jeweils mit einer erzeugten SKU und dem aktuellen Preis des Artikels. Danach können Sie Name, SKU oder Preis im Raster wie gewohnt bearbeiten, Barcodes anhängen und den Bestand pflegen.
5. Später einen Wert ergänzt — ein *XL*? Drücken Sie bei jedem Artikel, der das Set verwendet, erneut **Varianten erzeugen**. Es werden nur die fehlenden Kombinationen angelegt; vorhandene Varianten werden nie dupliziert, umbenannt oder entfernt, sodass ein erneuter Durchlauf immer sicher ist.

## Gut zu wissen

- Optionssets sind für eine **Palette echter Produkte** gedacht (Größen, Farben, Packungsgrößen) — jede Kombination ist eine eigene Bestandsposition. Für eine Wahl an der Kasse, die nicht ändert, was Sie auf Lager haben („extra Shot“, „ohne Zwiebeln“), verwenden Sie stattdessen die **Anpassungsoptionen** des Artikels.
- Die hier angelegten Werte werden geteilt: Dasselbe Set *Größe* kann T-Shirts, Hoodies und Tassen steuern. Eine Änderung, welche Sets ein Artikel verwendet, wirkt sich nur darauf aus, was **Varianten erzeugen** als Nächstes anlegt — bereits erzeugte Varianten bleiben unverändert.
- Eine von Hand im Raster eingetragene Variante lässt der Generator unangetastet, auch wenn ihr Name zufällig einem Wert entspricht.
- Optionssets gelten geschäftsweit und werden von der **Hauptkasse** aus verwaltet: An einer beigetretenen Kasse zeigt das Anlegen eines Sets oder das Erzeugen von Varianten eine Meldung, die Sie zur Hauptkasse zurückverweist.
