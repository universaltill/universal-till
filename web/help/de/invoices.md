# Rechnungen & Steuerrechnungen

Stellen Sie für einen Verkauf eine ordentliche (Steuer-)Rechnung aus — für Geschäftskunden oder überall dort, wo eine titulierte Rechnung erforderlich ist.

## Verwendung

1. Öffnen Sie „Rechnungen“, wählen Sie den Verkauf aus und füllen Sie die Kundendaten aus.
2. Drucken Sie sie oder drucken Sie eine beliebige frühere Rechnung aus der Liste erneut.

Die Liste (und ihre Schaltfläche für den CSV-Export für den Steuerberater) zeigt standardmäßig den laufenden Monat und später an — erweitern Sie das „Von“-Datum, um ältere Rechnungen zu erreichen.
