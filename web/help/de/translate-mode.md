# Übersetzungsmodus

Der Übersetzungsmodus zeigt, woher jeder Text auf der Kasse stammt. So kann ein Übersetzer ihn an der Quelle korrigieren, und ein Manager kann ihn für dieses Geschäft umformulieren. Nur Manager können ihn nutzen, und auf einem Selbstbestellungs-Kiosk und in der öffentlichen Demo ist er nie verfügbar.

## Einschalten

1. Öffnen Sie **Menü → Übersetzungen**.
2. Tippen Sie auf **Übersetzungsmodus einschalten**. Die Seite wird neu geladen, und die Statusleiste zeigt **Übersetzungsmodus**.
3. Zum Beenden tippen Sie in der Statusleiste auf **Ausschalten**.

Der Übersetzungsmodus bleibt in diesem Browser eingeschaltet, bis Sie ihn ausschalten. Meldet sich jemand ohne Manager-Berechtigung an, zeigt die Kasse normale Seiten.

## Einen Text öffnen

- Mit der Maus: Halten Sie **Alt** gedrückt und klicken Sie auf den Text. Manche Linux-Desktops verschieben mit Alt+Klick Fenster; öffnet sich nichts, nutzen Sie langes Drücken oder die Tastatur.
- Auf einem Touchscreen: Halten Sie den Text etwa eine halbe Sekunde gedrückt. Im Übersetzungsmodus öffnet langes Drücken den Bereich, statt den Text zu markieren, und eine gedrückt gehaltene Verkaufstaste startet nicht das Umsortieren der Tasten.
- Mit der Tastatur: Setzen Sie den Fokus auf eine Schaltfläche, einen Link oder ein Feld und drücken Sie **Alt+Eingabe**. Reiner Text wie eine Überschrift kann den Fokus nicht erhalten; nutzen Sie dafür Alt+Klick oder langes Drücken.

Am Bildschirmrand öffnet sich ein Bereich. Die Seite bleibt bedienbar, sodass Sie den nächsten Text öffnen können, während der Bereich offen ist.

## Was der Bereich zeigt

- **Schlüssel**, **Bereich**, **Beschreibung**, **Platzhalter** und **Längenbegrenzung**: das, was Übersetzer zu diesem Text sehen.
- **In Weblate öffnen**: öffnet diesen Text im gemeinsamen Übersetzungsdienst, in der Sprache, die die Kasse gerade zeigt. Der QR-Code öffnet denselben Link auf einem Handy oder einem anderen Computer. Die Kasse zeigt nur den Link an; sie verbindet sich nie selbst mit Weblate.
- **Eigene Formulierung**: ändert die Formulierung nur auf dieser Kasse, wie im Übersetzungseditor. Zurücksetzen stellt den eingebauten Text wieder her. Laden Sie die Seite neu, um die Änderung zu sehen.
- **Bereiche auf dieser Seite**: die Gruppen im Übersetzungsdienst, zu denen die Texte dieser Seite gehören. Laden Sie einen Übersetzer zu diesen Bereichen ein, damit die ganze Seite abgedeckt ist.

Ein Text, der aus einem Plugin stammt, hat keinen Weblate-Link: Er wird mit diesem Plugin übersetzt.
